# 实验、模型选择与最终评价协议

数学口径见 [METHODOLOGY.md](METHODOLOGY.md)，程序入口见 [README](../README.md)。本文件只维护实验程序和判定标准。

## 开发程序

1. 情景 1–120 是唯一开发总体。运行前在 `configs/benchmark.json` 固定种子、候选、搜索预算、期限和成本。每次使用新目录，保留配置、环境、代码/分区 hash、训练参数、划分和调参记录。
2. 外层 5 折随机整情景划分，每折验证 24 条、训练 96 条。每个外层训练集再做 3 折整情景 CV，对四类门控策略分别在四组 `(gamma,buffer)` 中选择。共 4×4×3×5=240 次内层候选/折评价；未来扩展还应记录失败候选。
3. 均值、协方差、最优权重、归一化、早停和特征选择均只能使用该层训练 IDs。不能把外层验证情景用于任何选择；评价入口拒绝训练/评价 ID 重叠。
4. 内层在 H=30、官方费用下使用 `real_CAGR−0.10×real_MDD`。这是研究偏好，**不是官方评分**；系数表达不同量纲/时间解释下的取舍，不是普适换算率。费用已经包含在财富中。
5. 每个策略族选择与最优均值相差不超过一个配对标准误的候选，优先较大 buffer，再较大 gamma。这是稳定性启发式，不是统计检验；保存全部候选及选择结果。
6. 用外层训练数据重拟合，在未参与该折调参的情景上评价 H=5、6、15、25、30。当前策略不依赖期限，可截取同一完整路径；期限相关 MPC/RL **必须逐期限重新实例化和模拟**。
7. 在 H=30 追加 0、0.125%、0.5%、1% 费用率。拟合参数不重调，但策略可根据新的成本作出不同决定。这是策略响应敏感性，不是按每种成本重新挑选赢家。

固定配置参照无训练参数，其 OOF 结果等同直接开发评价。学习策略的 OOF 结果评价的是“在 96 条情景上拟合/选择的程序”，不是最终在 120 条上拟合的单个模型。全开发集重拟合结果不能冒充独立评价。

## 路径风险约束选择研究（2026-10-14 预声明）

配置为 `configs/path_risk.json`，登记为 `development_path_risk_study`。一次研究生成 `control/` 和 `constrained/` 两个新运行，二者仅改变 `selection_rule`，共享整情景折、种子、训练估计和全部评价设置。每族8组参数为 gamma=3/8/16/32 与 buffer=0/0.001 的组合，window=5；两运行合计960次候选/内折评价。不追加事后参数或种子。

约束运行在每个外层训练集内部汇集三内折的折外路径。候选只有同时满足 `P90(MDD)≤P90(MDD_balanced_annual)+0.01`、`P10(CAGR)≥P10(CAGR_balanced_annual)−0.001` 才可进入原效用的一标准误选择。参照与候选初始权重均为50/35/15。这里用经验分位数筛选，未声称内层统计认证；每个外层评价集不参与阈值、参数或权重选择。

若没有可行参数，以最小P90回撤的候选继续完成诊断评价，明确输出不可行状态，不删除策略族或情景；freeze 拒绝该策略族。最终全开发集重选也须可行。这是显式研究诊断，不是生产回退或成功满足约束。

两个选择程序按相同情景进行配对bootstrap，报告边际中位/尾部分位数之差。四策略族调整只保护同一指标×期限×成本内的这四项比较，不保护其他端点或重复研究；仍沿用原增长路线晋级标准。内层约束成功但外层失败时如实报告，不能根据失败重新放宽风险标准。真实最终留出集继续封存。

## 固定目标与情景效用效率实验（2026-10-15 预声明）

执行用户确认的 `METHODOLOGY.md` 草案，配置为 `configs/efficiency.json`、登记为 `development_efficiency`。一年/三年估值各六组band/buffer，共180次候选/内折评价，CRRA gamma=5固定；它与旧均值方差gamma不是同一效用标尺。只使用原种子和1–120开发情景，不追加候选或状态预测。两候选共同使用25%已观察回撤复核规则；另加相同复核规则的年度参照，以识别暂停本身对交易频率的影响。

内层先用完整折外情景的点估计筛选中位/P10增长差≥−0.001/年、P90回撤差≤0.01、交易率≤年度Balanced一半、平均实际费用不增加。可行参数按交易率、实际费用、负中位增长、trial编号依次最小选择。无可行参数时，以五项违反量的最大值最小选择诊断；分母分别为0.001、0.001、0.01、参照一半交易率和参照实际费用，下限1e-12。诊断继续参与全部外层评价，但不能冻结。

外层效率推断预声明20,000次完整情景配对bootstrap，端点为中位CAGR差、P10 CAGR差、P90 MDD差、`mean(trade_candidate−0.5 trade_reference)`及平均实际费用差。调整覆盖2策略×5端点×官方及双倍2费用共20项比较，双侧尾概率0.05/(2×20)。增长下界须≥−0.001/年、回撤上界≤0.01、交易及费用约束上界≤0；该族全部内层选择可行且两档费用10项区间条件均通过，才标记开发效率筛选通过。其他期限/费用及同复核参照为诊断，原增长路线单独报告。区间仍条件于已拟合OOF模型，不能认证真实服务效果。

保存所有内层训练分布及其ID/片段来源、全部候选、失败状态、外层账本和代码/输入版本；重放验证独立重建训练片段、用幂均值形式复算CE效益及等待状态。客户候选风险按各自期限评价，一侧界对三原组合加两候选的五项选择保护，仅作诊断，不按本轮结果自动修改分配。冻结还须团队确认服务假设与适配性，本轮不执行真实冻结或最终评价。

## 统计解释与重复试验

配对 bootstrap 重抽样的是**完整情景 ID**，保留策略/参照对应和路径指标。95% 百分位区间针对边际中位数或尾部分位数之差，不是逐情景差的中位数。胜率为配对场景中严格优于参照的比例，平局不计胜。

`family_lower/upper` 在单个“指标×期限×成本”内，对多候选使用 Bonferroni 尾概率；不覆盖全部图表、端点、期限、成本及研究迭代。4,000 次 bootstrap、16 个比较时，极端端点只依赖约 6 次抽样，较粗糙。把它作为保守探索筛选，不能声称精确覆盖保证。

OOF 训练折重叠；当前 bootstrap 不重新拟合，因此遗漏训练不确定性，也不能消除共享训练样本的依赖。固定策略没有这一训练重叠问题。n=120 的 P90 尾部只有约 12 条路径，n=60 只有约 6 条。

Pareto 同时考虑中位 CAGR、P10 CAGR 越高越好，P90 MDD、实际费用越低越好。它是点估计的描述性支配关系，不含不确定性，不能单凭微小 Pareto 优势采用模型。独立性依据来自题目，而不是对生成器的统计证明。

持续查看外层 CV 仍会过拟合有限开发样本。用 `benchmark/experiment_registry.json` 记录日期、搜索预算、所有尝试与事后修改，限制候选数量。换随机种子只是一项稳定性研究，不是新的独立证据。嵌套 CV 约束预声明的内层搜索，不能消除无限次人工改模型的偏差。

## 新模型的比较与晋级

运行 MoE、MPC、RL 或稳健优化前，声明目标和可比较的简单参照。至少保留官方等权、同初始 Balanced 年度/持有参照和最相关的门控基准。比较期限、成本、训练数据、动作时点和可用信息必须一致。若声称时机选择改进，应匹配初始配置与可行敞口；不同风险约束下的成长/均衡组合差异不能全部归因于架构。

以下情况直接拒绝：信息泄漏、非法权重或核算、缺乏交易收益估计、隐藏求解失败、删除失败情景、无法解释动作、使用最终数据训练。频繁复核/回退应算作可靠性表现，不能删掉相关路径。真实人工介入的效果须有服务响应证据。

默认增长路线的晋级筛选，必须在实验前确定：

- 中位实际 CAGR 至少改善 0.10 个百分点/年，探索性多候选调整区间下界大于 0。
- P10 增长不能降低超过 0.10 个百分点/年，P90 MDD 不能增加超过 1 个百分点，按区间而非仅点估计判断。
- 至少 4/5 外层折方向一致，费用翻倍到 0.5% 后仍有增长优势。
- 复核频率、容忍度越界及计算失败符合预声明服务要求，并验证目标期限的客户适配。
- 保存参数/种子稳定性、训练/推理成本、动作解释以及同等表现的最简单策略。

改善增长却恶化风险时，报告取舍并进一步研究，不能宣称普遍胜出。风险降低型模型可事前反向声明：显著降低 P90 MDD，同时限制 CAGR 损失。未证明改进时保留简单参照，但不等于证明策略等效。`promotion_screen.csv` 只是探索性增长路线筛选，不是部署批准。

## 反事实离线强化学习研究（2026-10-15，执行前登记）

用户已要求执行第一条候选。主策略为`fqi_student`：用训练情景构建反事实动作，有限期限拟合Q迭代得到深度4的多输出回归树教师，再按教师Q值拟合深度2学生。`fqi_teacher`是配套教师诊断，沿用学生选中的惩罚；`fqi_portfolio`是去除滞后市场特征的学生消融，仍保留持仓/回撤信息。三者初始均为50/35/15，动作仅为保持或目标30/30/40、50/35/15、60/25/15。25%已观察实际回撤转人工，等待持有；与相同复核年度参照比较。无杠杆、卖空或额外资产。

配置为`configs/learning.json`。每训练折在官方/双倍两种费用下，分别生成持有及三个固定目标行为轨迹，从第2年起对每个状态模拟四个动作。状态含漂移权重、当前/历史最大实际回撤、上一年三资产实际收益/通胀、近三年权益实际收益均值/波动、费用率及复核状态，不含情景ID。期限k的训练只用至少还剩k个观测的前缀；k=1到29逐次拟合，评价按客户H逐期限重新模拟，禁止从30年路径截取短期限结果。

奖励为实际财富对数增长减去首次超过40%最大实际回撤的惩罚，惩罚仅取0.25、1.0。直接即期费用对数项解析扣除，回归目标不再重复扣除；交易须通过价值代理折算的费用/0.001缓冲门槛。未来价值使用上一期限教师及相同动作门槛，并计入持续复核后的保持。教师深度4、学生深度2、最小叶48、每特征至多16个分割点、动作优势缩放10均固定，不搜索种子/架构。

沿用5外折/3内折：2特征集×2惩罚×15内折=60次训练，另有20次外折重拟合；每次训练最多29个教师及29个学生。3报告策略×2惩罚×15内折=90次候选/内折评价，教师与学生共享训练。内层按30年原费用完整折外情景筛选中位/P10 CAGR差≥−0.001/年、P90 MDD差≤0.01；可行者依次最小P90回撤、40%越界频率、负中位增长、参数编号，无可行者最小最大标准化违反量，显式标记诊断。教师继承主学生参数，但独立记录所选教师是否可行。

主张为降低路径风险并限制增长损失：相对年度Balanced，原/双倍费用下P90回撤差调整上界须≤−0.01，中位/P10 CAGR差调整下界均须≥−0.001/年；三策略×三端点×两费用共18项Bonferroni区间，完整情景配对bootstrap20,000次。还须全部内层选中参数可行。旧增长路线另报，交易/费用、同复核参照和教师压缩差异为诊断。客户A–E按真实H统计容忍度越界，对原三组合加三学习策略共六选项调整一侧概率上界；高流动性规则不变，结果不自动重新分配客户。

保存每折反事实状态/后继/奖励、来源IDs、模型树、Bellman训练摘要、全部候选内层逐情景指标及逐期限完整账本。独立核验训练来源、即时费用/风险递推和部署动作。训练状态扩增不增加独立情景数；区间条件于已拟合OOF模型，不能消除本项目反复开发的偏差。本轮仅开发研究，新策略不开放真实freeze/final；若需最终评价，须另行完善并审查冻结序列化与客户适配。本轮不追加搜索、不读取121–180。

## 小型神经网络路径约束研究（2026-10-16，执行前登记）

用户已要求按首选方案执行。三类策略为`neural_linear`（全特征线性logits）、`neural_mlp`（全特征16×16 tanh）、`neural_portfolio`（去掉滞后市场特征的同容量MLP）。每类固定种子17、29，分别训练120轮，保留60/120检查点；部署平均两个成员的目标权重，不挑选种子。三类初始50/35/15，输出是20/35/45、50/35/15、50/25/25三个目标的凸组合，新目标权益≤50%；保持和复核等待仍可产生持仓漂移。主研究不是持续敞口保证。

状态复用已有因果特征并加剩余期限，市场特征仅用t−1及更早数据，标准化仅用训练情景；MLP参数约几百个。费用门槛复用训练折均值/收缩协方差的固定gamma=5一年效用代理，`u(w)=1+mu·w−gamma·wΣw/2`，`benefit=(u(target)−u(current))/u(target)>真实费用比例+0.001`才允许交易，估计无效则转人工。25%已观察实际回撤触发持续复核，等待持有。可微训练和部署使用相同硬门槛，不使用训练时的光滑交易替代；分支内求梯度，跨门槛不声称可微或全局收敛。

训练按H=5/6/15/25/30循环，原/双倍费用同时批量模拟，真实扣费后再应用收益和通胀；初始建仓固定收费。目标最大化平均年化实际对数增长；训练约束是每期限/费率的路径MDD经验CVaR90≤同训练情景年度Balanced的对应CVaR90−0.01，最差10%年化对数增长尾均值≥参照尾均值−0.001。对数增长尾均值不是P10 CAGR。两个约束分别按0.01和0.001标准化，用投影原始/对偶更新；超出容差则显式不可行。固定Adam学习率0.003、对偶率0.02/上限100、梯度裁剪5、L2系数0.0001，训练120轮，不追加架构、学习率、种子或风险阈值搜索。

5外折/3内折共20次训练折，3策略×2种子×20=120个网络训练；各网络保留两检查点，不重训检查点。内层3策略×2检查点×15折=90次候选/内折评价。内层按30年原费用完整折外情景筛选中位/P10 CAGR差≥−0.001/年、P90 MDD差≤−0.01；可行检查点最大中位增长，再最小P90、较早轮数；无可行检查点按最大标准化违反量最小，标记诊断，不删除情景。

最终开发通过条件为：所有外折所选检查点内层可行、外折重拟合后所选双种子组合的全部训练约束可行，并且三策略×三端点×原/双倍费用18项配对调整区间中的该策略六项均通过。中位/P10年增长损失上界0.001，P90回撤至少改善0.01；bootstrap20000次，按完整情景抽样，区间条件于已拟合OOF模型。原增长路线另报，客户A–E按对应H独立模拟，对原三组合加三新策略六选项调整一侧概率上界，不自动改变客户分配。

保存原始训练市场张量及来源IDs、标准化、每个种子/检查点参数、对偶/梯度/约束轨迹、训练与部署核对、全部内层结果和完整逐期限账本。使用CPU float64及固定线程、确定性算法；独立NumPy重放检查网络、费用门槛、路径MDD及训练约束，生成数据用有限差分检验梯度。新增依赖统一在pyproject/根lock维护。该研究只开放开发入口；不执行真实冻结/最终评价，不读取121–180。任何优化不可行、运行或核验失败保留并报告。

## 冻结与一次性最终评价

开发时不要运行真实最终评价。团队完成模型选择后，从项目根目录执行：

```bash
.venv/bin/python benchmark/run.py freeze --policy cost_aware \
  --development-run benchmark/outputs/development_consolidated \
  --bundle benchmark/frozen_policy.json
.venv/bin/python benchmark/run.py final --bundle benchmark/frozen_policy.json \
  --out benchmark/outputs/final --acknowledge-final
```

`cost_aware` 只是命令示例，不表示推荐采用。freeze 检查开发运行与当前代码、配置、数据一致，在全部 120 条开发情景上执行声明过的内层选择和重拟合，保存候选、参照、参数、环境/hash、冻结后的客户分配及最终情景 IDs。文件只能新建；这一阶段不评价最终数据。

final 验证 bundle 完整性、代码/环境和开发数据，然后在读取任何最终收益前创建 `benchmark/FINAL_EVALUATION_LOCK.json` 独占锁。按预声明期限和成本生成最终结果；即使换输出目录，也拒绝第二次运行。客户分配只评价，不根据最终结果重新推荐。

创建锁后若崩溃，锁仍视为已使用；须由独立保管者确认暴露了哪些信息并记录恢复理由，不能为换模型而删锁。可以从保存结果重新生成报告，这不重新读取市场 CSV。
