# 实验、模型选择与最终评价协议

数学口径见 [METHODOLOGY.md](METHODOLOGY.md)，程序入口见 [README](../README.md)。本文件只维护实验程序和判定标准。

## 开发程序

1. 情景 1–120 是唯一开发总体。运行前在 `configs/benchmark.json` 固定种子、候选、搜索预算、期限和成本。每次使用新目录，保留配置、环境、代码/分区 hash、训练参数、划分和调参记录。
2. 外层 5 折随机整情景划分，每折验证 24 条、训练 96 条。每个外层训练集再做 3 折整情景 CV，对四类门控策略分别在四组 `(gamma,buffer)` 中选择。共 4×4×3×5=240 次内层候选/折评价；未来扩展还应记录失败候选。
3. 均值、协方差、最优权重、归一化、早停和特征选择均只能使用该层训练 IDs。不能把外层验证情景用于任何选择；评价入口拒绝训练/评价 ID 重叠。
4. 内层在 H=30、官方费用下使用 `real_CAGR−0.10×real_MDD`。这是研究偏好，**不是官方评分**；系数表达不同量纲/时间解释下的取舍，不是普适换算率。费用已经包含在财富中。
5. 每个策略族选择与最优均值相差不超过一个配对标准误的候选，优先较大 buffer，再较大 gamma。这是稳定性启发式，不是统计检验；保存全部候选及选择结果。
6. 用外层训练数据重拟合，在未参与该折调参的情景上评价 H=5、6、15、25、30。新增期限相关专家/RL后，所有新运行均逐期限重新实例化和模拟；历史期限无关运行保留原路径前缀口径。
7. 在 H=30 追加 0、0.125%、0.5%、1% 费用率。拟合参数不重调，但策略可根据新的成本作出不同决定。这是策略响应敏感性，不是按每种成本重新挑选赢家。

固定配置参照无训练参数，其 OOF 结果等同直接开发评价。学习策略的 OOF 结果评价的是“在 96 条情景上拟合/选择的程序”，不是最终在 120 条上拟合的单个模型。全开发集重拟合结果不能冒充独立评价。

## 统计解释与重复试验

配对 bootstrap 重抽样的是**完整情景 ID**，保留策略/参照对应和路径指标。95% 百分位区间针对边际中位数或尾部分位数之差，不是逐情景差的中位数。胜率为配对场景中严格优于参照的比例，平局不计胜。

`family_lower/upper` 在单个“指标×期限×成本”内，对多候选使用 Bonferroni 尾概率；不覆盖全部图表、端点、期限、成本及研究迭代。4,000 次 bootstrap、16 个比较时，极端端点只依赖约 6 次抽样，较粗糙。把它作为保守探索筛选，不能声称精确覆盖保证。

OOF 训练折重叠；当前 bootstrap 不重新拟合，因此遗漏训练不确定性，也不能消除共享训练样本的依赖。固定策略没有这一训练重叠问题。n=120 的 P90 尾部只有约 12 条路径，n=60 只有约 6 条。

Pareto 同时考虑中位 CAGR、P10 CAGR 越高越好，P90 MDD、实际费用越低越好。它是点估计的描述性支配关系，不含不确定性，不能单凭微小 Pareto 优势采用模型。独立性依据来自题目，而不是对生成器的统计证明。

持续查看外层 CV 仍会过拟合有限开发样本。用 `benchmark/experiment_registry.json` 记录日期、搜索预算、所有尝试与事后修改，限制候选数量。换随机种子只是一项稳定性研究，不是新的独立证据。嵌套 CV 约束预声明的内层搜索，不能消除无限次人工改模型的偏差。

## 新模型的比较与晋级

运行 MoE、MPC、RL 或稳健优化前，声明目标和可比较的简单参照。至少保留官方等权、同初始 Balanced 年度/持有参照和最相关的门控基准。比较期限、成本、训练数据、动作时点和可用信息必须一致。若声称时机选择改进，应匹配初始配置与可行敞口；不同风险约束下的成长/均衡组合差异不能全部归因于架构。

以下情况直接拒绝：信息泄漏、非法权重或核算、缺乏交易收益估计、隐藏求解失败、删除失败情景、无法解释动作、使用最终数据训练。频繁复核/回退应算作可靠性表现，不能删掉相关路径。真实人工介入的效果须有服务响应证据。

默认增长路线的晋级筛选，必须在实验前确定：

- 中位实际 CAGR 至少改善 0.10 个百分点/年，探索性多候选调整区间下界大于 0。
- P10 增长不能降低超过 0.10 个百分点/年，P90 MDD 不能增加超过 1 个百分点，按区间而非仅点估计判断。
- 至少 4/5 外层折方向一致，费用翻倍到 0.5% 后仍有增长优势。
- 复核频率、容忍度越界及计算失败符合预声明服务要求，并验证目标期限的客户适配。
- 保存参数/种子稳定性、训练/推理成本、动作解释以及同等表现的最简单策略。

改善增长却恶化风险时，报告取舍并进一步研究，不能宣称普遍胜出。风险降低型模型可事前反向声明：显著降低 P90 MDD，同时限制 CAGR 损失。未证明改进时保留简单参照，但不等于证明策略等效。`promotion_screen.csv` 只是探索性增长路线筛选，不是部署批准。

## 专家研究的预注册扩展（2026-10-16）

`development_experts_v1`追加5个候选，仍保留17种原策略及原调参程序。三个学习门控分别搜索两种回撤惩罚0.1/0.3，使用相同内层整情景划分；每个拟合都固定三种子概率集成，禁止选最好种子。规则候选不依赖惩罚参数，重复评价仅为共用比较表，不构成不同模型。架构和训练预算见唯一配置及实验登记。

主要参照是`balanced_annual`，主要路线是风险下降。内层H=30选择要求：中位CAGR差≥−0.005，P10增长差≥−0.002，P90回撤差≤−0.03。可行者优先更低P90，再更高增长，完全并列偏好较大惩罚。均不满足时，最小化三项超限量除以各自门槛之和，明确输出`risk_selection_feasible=false`；这个候选仅供研究评价，不冒充约束已满足。

外层晋级要求同时满足：P90点估计下降至少3个百分点且探索性多候选调整区间上界<0；中位CAGR和P10增长的调整区间下界分别不低于−0.5和−0.2个百分点；至少4/5折P90下降；费用翻倍后仍达到点估计风险下降及中位增长容忍度；无无效估计/网络执行回退。客户期限风险单独报告，不能由这个筛选替代。原增长路线筛选继续输出，不提供虚构官方综合分。

同一候选另外比较等权及同专家集合的`expert_greedy`，并记录三种子各自的折外表现。种子结果仅诊断稳定性，不用于择优。H=5/6/15/25/30实际策略分别模拟，客户风险表以五个候选作单客户的同时一侧界；流动性规则和入门分配不因此自动更改。

不据外层结果无限扩展候选。任何后续想法须另登记实验、新建输出目录，保留本次失败结果和hash。执行阶段保持真实最终情景121–180封存。

## 冻结与一次性最终评价

开发时不要运行真实最终评价。团队完成模型选择后，从项目根目录执行：

```bash
.venv/bin/python benchmark/run.py freeze --policy cost_aware \
  --development-run benchmark/outputs/development_consolidated \
  --bundle benchmark/frozen_policy.json
.venv/bin/python benchmark/run.py final --bundle benchmark/frozen_policy.json \
  --out benchmark/outputs/final --acknowledge-final
```

`cost_aware` 只是命令示例，不表示推荐采用。freeze 检查开发运行与当前代码、配置、数据一致，在全部 120 条开发情景上执行声明过的内层选择和重拟合，保存候选、参照、参数、环境/hash、冻结后的客户分配及最终情景 IDs。文件只能新建；这一阶段不评价最终数据。

final 验证 bundle 完整性、代码/环境和开发数据，然后在读取任何最终收益前创建 `benchmark/FINAL_EVALUATION_LOCK.json` 独占锁。按预声明期限和成本生成最终结果；即使换输出目录，也拒绝第二次运行。客户分配只评价，不根据最终结果重新推荐。

创建锁后若崩溃，锁仍视为已使用；须由独立保管者确认暴露了哪些信息并记录恢复理由，不能为换模型而删锁。可以从保存结果重新生成报告，这不重新读取市场 CSV。

该机制预防误操作，不对抗人为改代码或复制项目。更可信的做法是由另一位成员保管最终数据、签署冻结方案并执行。目录整合后的真实 freeze/final 尚未运行；自动测试只在生成的零收益数据上验证最终流程。

最终评价后应报告全部声明过的指标，不再调参。失败就报告失败；修改后的模型需要新的独立数据。60 条最终情景不能认证罕见风险、真实执行或实盘效果。

## 单因素后续实验（2026-10-16）

查看`development_experts_v1`后发现30年官方费用下战略专家从未被选中，规则门控退化为纯防御专家。预登记`development_experts_v2`仅把共享门槛的基础gamma从8改为3（采用历史简单策略已经使用的值），保留回撤/期限项、专家配置、网络、训练预算、划分、种子和晋级标准。当前配置对应v2，v1配置留在其不可改写的运行快照。此实验受v1外层结果启发，不能作为新的独立证据；完成后停止本轮配置扩展并报告两版。

## 提交版路径风险预注册（2026-10-16）

用户授权继续迭代后登记`development_frontier_v1`，保留此前全部尝试。新增三类研究：路径风险预算配置及持有/年度参照、短期/多期情景交易规则、线性/神经价值近似。两组固定设置为尾均回撤预算相对于等权的1.0/0.9倍，分别配回撤惩罚0.1/0.3；不声称这是独立单因素消融。所有方法在相同设置下共用初始配置及三种动作。

训练内对5%配置网格和等权参照完整核算含成本路径，最大化中位增长，约束最大回撤的90%尾均值不超过预算且P10增长损失不超过0.1个百分点；不可行时保留最小违约及不可行标记。网格全枚举只保证离散候选上的最优，不声称连续全局最优。各客户期限独立选择配置。

内层同时评价五个期限，先按原30年风险路线标准计算违约量，再以五期限平均增长减0.1倍回撤排序。外层增长/风险晋级条件均保持。线性和神经模型只近似训练场景规划器，固定600个训练状态、160轮和三个种子，不根据外层挑种子。既有RL补齐历史最大回撤，并让无状态对照使用同监督训练预算。

正式选型前检查全部候选、费用翻倍、各期限客户适配、同配置年度/持有/短期门控差异、运行故障及复核比例。不要求复杂模型胜出，不以反复调外层直到显著作为停止条件。完成该批次后仅在有可定位缺陷或明确新假设时另登记迭代。最终方案及比较列表冻结之后才读取121–180，最终结果无论成功与否均报告，不再据此调参。

第二批`development_frontier_v2`在看到首批失败后登记：训练配置预算改为相对Balanced的P90回撤下降3/5个百分点，分别搭配0.01/0.03回撤惩罚；固定风险违约系数0.5与1个百分点容差。策略价值另减去`0.5 × max(0, P90(action)−P90(strategic)−0.01)`，其中两种预测均在相同当前状态及续行假设下计算，不能宣称这是实际路径的硬风险保证。原晋级条件不改。为辨别交易价值，新增参数完全相同的年度/持有/短期参照。费用近似的常量输入修正属于实现修复，不额外扫描参数。用户要求暂停报告、论文与提交材料；真实最终留出集继续封存。

平滑风险偏好批次`development_cushion_v1`：gamma在财富峰值固定为4，仅搜索回撤预算0.4/0.5，buffer固定0.0001，配置步长0.025。令d*=min(当前回撤,L−0.02)，gamma=4L(1−d*)/(L−d*)；该式来自带购买力缓冲的风险厌恶启发式，不提供真实财富底线保证。固定gamma对照不依赖L，两次重复内层评价不算两个独立模型。所有原晋级阈值保持。与frontier_v2共用外层已训练模型和划分，新的超参数仅在各外层训练集的内层选择；旧候选完整重新评价并核验财务指标相同。此批次是已看开发结果后的新研究，不消除人工反复试验偏差。

`development_cushion_v2`预登记固定战略先验权重1、风险反馈强度0.5，继续仅搜索预算0.4/0.5，网格/成本余量/gamma峰值均不变。依据是首版静态均值估计也改变了股票/债券结构，且动态反馈过强会牺牲增长；用逆优化先验及减半反馈检验更稳定的配置调整。两项结构同时改变，不把结果当作单因素归因。原晋级条件保持、首版失败保留；此后据全部开发证据确定最可靠方案，不能放宽标准或反复读取最终情景制造成功。

简单参照校准`development_calibrated_v1`：只在同内层划分搜索经验均值方差gamma=4/4.5/5，固定buffer=0.0001和2.5%网格、原Balanced初始配置；固定gamma4单独保存。该族不采用逆优化先验和回撤反馈。理由是此前简单成本门控按增长效用在3/8选择，并未按新增模型相同风险路线校准；本轮补齐对照而不是更改晋级条件。复用同外层训练矩估计，33个旧候选原参数全部重新评价并核验一致。
