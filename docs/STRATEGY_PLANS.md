## 计划 A：路径风险配置与成本感知交易

### A1. 建立可求解的战略配置

设训练情景s的实际收益向量为r(s,t)，固定年度目标权重为w，满足w≥0、Σw=1。先考虑不计费用的战略子问题：

```text
g_s(w) = (1/H) Σ_t log(1 + r(s,t)ᵀw)
Y_s(w) = max_{0≤u≤v≤H} {−Σ_{t=u+1}^v log(1 + r(s,t)ᵀw)}
D_s(w) = 1 − exp(−Y_s(w))

maximize    mean_s g_s(w)
subject to  z + Σ_s a_s/[N(1−α)] ≤ b
            a_s ≥ Y_s(w)−z, a_s ≥ 0
            w ≥ 0, Σw = 1
```

这里Y是最大对数回撤，D是通常的最大比例回撤，α初始取0.9。空区间u=v使Y非负。每个负对数项凸，区间求和与最大值保持凸性，所以Y凸；目标凹，以上是凸优化问题。这一证明适用于固定再平衡权重、无费用的战略子问题。

上尾均值约束作用于**每条路径的最大对数回撤**；它不同于年度收益CVaR，也不同于把所有时点回撤池化后的CDaR。`CVaR(Y)≤b`不能写成`CVaR(D)≤1−exp(−b)`的等式。该约束可控制训练分布的相应分位数，但不构成未来损失上限。

算法先复用231点网格做可行性和数量级核验，再实现连续凸求解器。采用辅助变量及最严重区间的割平面，避免一次生成所有N×H²约束。保存原始/对偶残差和约束余量；不可行明确返回。正式选择同时检查含费用、含实际交易规则的路径，不能用战略子问题的凸性替完整系统背书。

三类组合分别采用严格、中等、宽松的风险预算，并逐客户期限评价。本轮25%/35%/45%只用于研究风险前沿，不直接定为三类产品标准；最终预算还要检查损失容忍度映射、可行性和敏感性。

### A2. 从交易价值推导不交易区域

候选动作至少包括保持、回到战略目标、只向目标移动一部分。先用离散的移动比例0/0.25/0.5/0.75/1；若结果稳定再考虑连续求解。给定交易前权重p：

```text
f(w,p) = c × ||w−p||₁ / 2
score(w,p) = (1−f(w,p)) A_t(w)
B(w,p) = [A_t(w)−A_t(p)] / A_t(w)
trade only if B(w,p) > f(w,p) + buffer
```

A必须是正的、事前声明的风险调整价值代理，可用经战略锚定的二次效用或情景确定性等价值；保持动作始终参与比较。不交易区域是所有候选改善都不足以覆盖费用的状态集合。增加估计不确定性时，在训练情景重抽样下检查净改善下界；下界阈值是稳健决策规则，不能冒充逐次交易的同时覆盖保证。

严格区分两个机制：带宽减少换手；收益门槛使交易满足题意。只有前者的实验结果不能当作后者的表现。最终应在内层评价完整执行策略并重新检验风险预算。

### A3. 工程与验证

- 新增战略优化模块和交易门槛模块；复用现有引擎，不重写扣费口径。
- 工厂显式接收客户期限H，期限相关策略逐期限重新模拟。
- 对照：官方等权；相同战略权重的年度/持有；相同权重的完全恢复/部分恢复；有无费用门槛。
- 指标：题目要求的四个分位数、普通波动、交易率，再加实际费用、客户容忍度越界率和拒绝服务率。
- 检查：连续解与细网格的目标差、含费可行性、五折权重稳定性、费用翻倍、尾部路径顺序扰动。
- 通过条件：能完整连接客户与执行规则；相对公平对照有可重复的增长/风险取舍，或以更少交易达到相近结果。只有少交易而风险增加时，明确标注取舍。

估计研发量：约1个工作日完成首个完整版本；具体取决于凸求解器依赖与风险门槛校准。最可能成为完整答案的主体。

## A的复盘与有限改进

A已经完成三产品、实际期限、费用门槛、解释、人工复核、凸子问题证书与完整验证流程；同风险线内层合格从7/15到15/15。它适合作为最终可交付的基线，但不能称为稳定优胜：同锚年度增长4.2828%、P90回撤42.6963%，自动策略4.3401%/42.2199%，增量区间跨零。平均实际费用0.7890降至0.6597，减少费用已建立；自动更新的总体投资价值尚未建立。题目允许得出自动更新增值证据不足的结论。

当前战略子问题最大化平均对数增长、约束无费固定年度目标的对数回撤；执行层则使用锚定二次偏好并部分交易。两层目标不同，前一层的凸最优性不保证后一层最优，更不直接最大化题目的中位数/P10/P90。仍应保留同配置对照和客户期限风险。

下一轮A只建议按以下优先级安排有限实验，不同时修改：

1. **按期限组校准安全余量。** 当前每产品共用一组风险比例/gamma，虽有H相关权重，却要求五期限同时合格。从已保存的均衡候选约束复算，未通过条件仅在H5（6项）和H6（7项）；H15/25/30没有失败项。这13项包含风险或收益损失条件，其中4项风险超限，不能全部称为风险失败。可预声明短期组{5,6}、长期组{15,25,30}，各组仍只搜索现有三比例×两gamma，固定验证风险线。两组分别选择，没有必要穷举36个联合组合。比较当前共享参数规则；完整外层重新选择和评价，不能用已看过的折外结果直接重选后宣称验证。先考察长期方案是否被短期约束不必要地压低收益。
2. **连续选择向锚移动的比例。** 保持均值、风险与锚不变，将五点lambda换成[0,1]上的一维求解，不增加可调统计参数。令C=1+mu_trainᵀa、q=(p−a)ᵀΣ(p−a)、k=c||a−p||₁/2，则沿线A(lambda)=C−gamma*q*(1−lambda)²/2，净代理S=(1−k*lambda)A(lambda)。在q>0、k<1时，S''=−gamma*q*(1+2k−3k*lambda)<0，可直接检查端点和导数根；无须随机优化。严格费用与buffer门槛仍须单独满足。该改动只消除动作离散误差，不承诺产生预测收益。
3. **检查产品风险前沿与客户目标。** 目前预算来自旧三产品配置，服务阈值是研究假设。若研究更低风险Balanced，应事先给出相对等权或客户容忍度的解释，再比较风险相近的增长，不仅以放宽风险增加增长。参考组合变更须作为独立新实验；不强求每位客户都入场或所有产品都被分配。

复核只作为模型/服务交接，等待时保持持仓的规则继续保留，不把偶然停止交易后的反弹收益当成止损价值。模型失效阈值与客户承受度是不同输入；如增加客户容忍度接近/越界触发，应单独检验服务频率，不和B/C主比较同时改变阈值。估计不确定性应按整情景重抽样；更保守的误差界可能进一步降低增长，不能同时宣称消除了不确定性且免费提高收益。

## 计划 B：可检验的预测增量

### B1. 先识别对配置有用的信号

股票、债券和bills的绝对实际收益可能共同受通胀影响。第一批主要预测股票相对bills的实际收益差y_t=r_equity_real−r_bill_real，而非因为单个资产R²为正就同时改变三种资产预测。

本轮仅对2026-10-16保存的3,360条折外预测作线性相减，未拟合新模型。相同特征标准化与Ridge惩罚下，目标线性变换与Ridge拟合可交换，所以这些差值对应同设置的收益差预测：

| 预测目标 | 相对同训练样本常数预测的折外R² | 误差改善的折数 |
| --- | ---: | ---: |
| 股票−bills | 1.2483% | 5/5 |
| 债券−bills | −0.1290% | 1/5 |
| 股票−债券 | 0.2114% | 2/5 |

该结果支持把股票/bills作为首要方向，不证明可交易收益或显著性；属于已反复使用的开发数据。债券条件信号先固定为零，不据当前数字继续搜索预测器。

建议固定现有12维因果特征：上一年三资产实际收益及通胀、最多五年均值/标准差、平均通胀、历史长度。只用训练路径标准化，Ridge惩罚lambda=10、截距不惩罚；第1/2年沿用A。增加仅用历史长度的模型作诊断，识别预测是否主要来自合成情景的年度位置。再用训练路径内固定循环移位标签作安慰剂；单个移位对照不是严格置换检验。

### B2. 正确地接入A的动作价值

当前A的均值仅出现在所有动作共享的常数1+mu_trainᵀa中；直接替换它不能提供方向性的条件收益。建议显式加入信号倾斜：

```text
delta_t = predicted(y_t | history) − training_target_mean(y)
A_B,t(w) = 1 + mu_trainᵀa
           − gamma*(w−a)ᵀΣ(w−a)/2
           + eta*delta_t*(w_equity−a_equity)
eta ∈ {0, .25, .5}
```

delta的均值基准必须来自与预测器相同的训练目标年份；不能把预测器第3..30年均值与A第1..30年均值差混入条件信号。主模型只增加股票条件收益，其他资产保留战略先验。保持原score与收益/费用门槛，A失效时按既有规则复核。eta=0且动作集合相同，动作、持仓和费用应逐点复现A。

建议两套动作集合、每套三档eta，共六个设置：

| 动作族 | 设置 | 能回答的问题 |
| --- | --- | --- |
| 原A五个向锚移动比例 | eta=0/.25/.5 | 预测是否改善再平衡时机，主比较 |
| 原动作＋a±0.05(e_i−e_j)的有效目标，最多11个动作 | eta=0/.25/.5 | 同样预测是否需要改变目标方向，次比较 |

扩展目标只保留非负、和为1且满足既定产品目标约束者，保持动作始终存在。扩展族eta=0是自己的无预测对照；不能把扩展后的eta=0当作原A，也不能将扩展动作的效果归给预测。

A的战略锚、风险目标、协方差、gamma、buffer、初始建仓、复核阈值在每对比较中完全一致。按外层96/内层64训练边界分别拟合A和预测器；A的预声明选择流程先完成，再在内层选择eta。不能将全96条拟合的锚或标准化器用于64/32的内层验证。eta选择只能使用该外层训练总体，外层24条不参与。两动作族分开比较，主检验预定为原动作族的预测增量。

预测数值失效或超出事先定义的训练适用范围时，撤销预测修正并回到A，记录回退率；A的风险预警仍转人工。回退不能删除该情景，也不能把回退后的结果算作预测器一直正常运行。

### B3. 具体输出、验收与停止

输出逐情景预测误差差、信号、所评动作价值、费用门槛、交易及最终财富；情景是推断单位，不能把3,360条年度预测当作3,360次独立试验。检验收益差预测、实际动作改变和扣费后价值三个环节，预测更准但没有行动/收益改善时保留失败结论。

主要评价H30，并在正式运行同时保存5/6/15/25/30年和既定费用敏感性，尤其0.25%/0.5%。沿用项目的增长/风险路线，以匹配的无预测版本为主要参考，并保留官方等权、原Balanced年度和A；阈值是项目研究标准，不是官方分数。平均实际股票暴露、普通波动与P90共同检查；更高股票暴露带来的增长不等于信号择时有效。必要时按内层风险匹配后再比较，不能根据外层结果事后调gamma。

第一批固定lambda和特征，只选择eta，不同时搜索模型家族。仅历史长度与移位信号作为诊断，不参与赢家选择。若信号优势被时间位置解释、费用翻倍后消失、绝大多数折选择eta=0，或超出固定风险目标，停止扩展；保留A作为答案。情景bootstrap估计信号不确定性可作为后续独立研究，不在第一批叠加多个风险惩罚参数。

建议代码：抽取既有特征/Ridge至`benchmark/safebench/signals.py`作为唯一实现，新建`plan_b.py`并复用引擎、选择和冻结；`tests/test_signals.py`验证因果前缀、训练分区、目标差线性变换和冷启动，`tests/test_plan_b.py`验证eta=0复现、费用门槛及匹配动作集合。抽取后不改写历史预测manifest。

## 计划 C：检验跨期规划本身的价值

### C1. 研究问题与准确状态

C检验未来换手、交易费用、已有回撤和剩余期限的协调是否值得规划。第一批不接B预测，B失败也不自动否定C；若B成功，预测＋规划须作为后续独立组合实验。

建议状态为(p,z,m,n)，其中p为当前权重、z=W/M为当前实际财富相对历史峰值、m为历史最大实际回撤、n为剩余期限。若加入期末相对初始购买力不足目标，还须记录W/W0。例：100→100→50→100与100→100→100→100当前财富、峰值、当前回撤完全相同，但历史最大回撤为50%与0%，不能混为同一状态。

当前PolicyContext仅有实际峰值，没有历史最大回撤字段；实现时应在共享contracts与引擎明确增加该状态，包含每次扣费后和年末标记，同步接口与冻结版本。剩余期限由工厂传入的H及当前period得到。复核待处理继续保持，不能让MPC自行结束复核。

### C2. 有限规划与费用一致的目标

只用四类因果动作规则：保持、执行A当前建议、完全恢复战略锚、转到训练得到的防御配置。加入“执行A”确保原规则可选；防御配置由同训练样本的固定网格最小路径风险选出，不称连续全局最优，也不把bill当购买力无风险资产。所有比较共享动作族和防御配置。

对L=1或3枚举4^L条动作类型序列，少于L个剩余期时截断。所有未来情景采用同一预定动作类型序列；权重可按各自当时持仓执行同一规则，不能看到某条未来路径后重新挑选最优动作。只执行首步，下一年重规划。

未来情景取本训练分区完整联合收益/通胀路径的对应年度段；内层64条、外层96条全部使用，所有候选及L1/L3共享同一批路径。不从评价情景抽取未来块，不拆开资产和通胀，不把序列条数当独立训练样本。L步后继续按A到客户期限末，直接评价全程路径，不再额外加一遍终值续接价值。

```text
J(U) = mean_s log(W_end,net(U,s) / W_now)
       − kappa * CVaR90(Y_end(U))
V_net(U) = exp(J(U))
```

Y_end是把已发生历史与预测未来合在一起的最大对数回撤。当前和未来费用均真实扣除。第一批主比较固定kappa=1，L1与L3完全匹配；kappa=0仅作移除风险项的诊断，不搜索大量风险权重。滚动最大回撤优化不据此获得时间一致性或全局最优保证；这是有限策略族的情景MPC。

为复用引擎费用门槛，令f0为候选首步费用占当前财富比例，V_hold为同样优化范围内首步保持的最佳净价值，定义A(U)=V_net(U)/(1−f0)，benefit=1−V_hold/A(U)，仅当benefit>f0+buffer才执行。这是净价值的记账分解，不能把模拟里已经扣掉的当前费用再扣一次；当前费用对路径风险的影响仍保留在V_net里。

### C3. 对照、计算预算与退出条件

主比较是C3对C1，检验多期规划；C1对A只用于检查动作/价值估计改变，不能称为三期优势。初始配置、风险目标、未来情景、费用、续接A和复核机制均一致。L3最多64条序列×96条未来路径=6,144条续接路径/决策，应采用NumPy批量模拟，并以标量引擎核验生成的小案例。

先做已登记的H30、0.25%/0.5%两档开发筛查，保存全部C1/C3与风险项消融；只有相对C1出现预定且可解释的增量，才执行已经规划好的全期限/全费用评价，不扩大动作或调风险偏好追逐外层结果。保存每个首步的增长、尾部风险、当前/未来费用分解、耗时、失败和复核次数。C3若没有比C1更好的折外净增长/风险取舍，或优势对路径顺序/费用不稳，就停止，不升级至深度RL。

建议代码：`benchmark/safebench/scenario_control.py`实现联合路径续接、状态更新、有限序列搜索，策略层只负责转成Decision；`tests/test_mpc.py`验证历史回撤记忆、费用一次计入、无未来信息、剩余期限截断、序列枚举和标量/批量一致。任何新增Context字段同时更新`src/safeinvest/contracts.py`和`docs/INTERFACES.md`，并保留旧类型兼容策略或明确升级版本。

## 共用的客户适配与可信服务

客户输入H、容忍度L、流动性，先评价实际执行策略在H年的MDD分布与终值购买力风险，再选三类中的合格者或转人工。三类组合不能只改变名称；它们应有可解释的风险差异并在各期限上检查。

关键事实：同一条期限无关策略的路径，H增加时最大回撤不会下降；长期终值亏损概率下降，并不说明长期路径回撤更小。因此不能仅凭“30年”把C分到Growth，也不能仅凭“25年”忽略D的15%容忍度。期限相关策略需要重新模拟，不再使用30年前缀捷径。

本轮的战略/门控探针没有完成新的A–E推荐。正式版本必须把实际策略ID连接到适配及最终评价。旧A/D人工、B/C/E保守的结果只代表旧规则，不能先决定新分配再寻找参数使其成立。

高流动性没有提款日期/金额，应采用显式的bill配置要求或询问不足时转人工，并对该假设做敏感性分析；不能虚构现金流。bill只在名义上接近现金，其购买力仍可能下降。

复核触发包括输入异常、模型估计失效、没有可接受动作、客户信息变化或已观察风险严重偏离计划。等待期间沿用题目允许且可模拟的既定动作，例如保持持仓并暂停自动更新；完整保留损失路径，报告触发率及等待暴露。拒绝服务和保持持仓都不能被描述成止损效果。

## 发散思路的取舍

| 思路 | 当前处理 | 理由 |
| --- | --- | --- |
| 全单纯形网格／凸配置 | 优先 | 三资产只有两个自由度，容易核验与解释 |
| 鲁棒均值／场景重加权 | 少量添加 | 可减少估计误差，但不把对数增长标准差惩罚随意声称为凸函数 |
| CVaR／路径回撤 | 优先对齐口径 | 年度损失、路径最大回撤和回撤时点池化是不同风险对象 |
| 部分再平衡／不交易区域 | 优先 | 本轮有正向线索，需补足收益门槛与完整策略风险校准 |
| 风险约束Kelly | 理论参照 | 原论文研究财富跌破初始水平的概率，并依赖重复收益假设；不能直接当成本题峰值回撤保证，bill也不是实际收益恒为零的安全资产 |
| HMM／GARCH市场状态 | 暂缓 | 固定二阶矩预测没有改善；应先证明条件分布有价值 |
| CPPI／回撤触发降仓 | 挑战者或反例 | 年度交易有跳跃风险，降仓可能损害恢复；本轮P10受到影响 |
| 随期限下降权益的生命周期规则 | 保留对照 | 需从终点购买力目标说明，不能假定能改善峰值回撤 |
| 风险平价／逆波动 | 简单参照 | 可说明配置效应，不单独解决路径尾部或交易价值 |
| 深度网络／强化学习 | 暂不作为主线 | 120条独立路径、弱信号与明确的可解释要求；旧分支也未证明稳定增量 |
| 神经网络近似MPC | 仅在实时计算确有瓶颈后考虑 | 先证明原规划有效，再验证近似误差及收益门槛，不把速度提升当投资收益提升 |
| 遗传算法／NSGA-II | 无需优先 | 当前低维可用网格、凸子问题及有限动作枚举，增加随机搜索不自动增加模型质量 |
