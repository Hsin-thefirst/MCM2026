## 优先修正的问题

| 问题 | 处理 | 原因 |
| --- | --- | --- |
| 第4节留有“Otherwise, ...”，部分语法不完整 | 补全复核优先、候选排序、成本检查和动作分类 | 读者应能按文字复现分支 |
| “没有候选通过”与代码不完全一致 | 明确只检查得分最高的候选，失败就保持，不尝试次优候选 | 避免把执行规则写成另一种算法 |
| 再平衡容易与回到战略锚混淆 | 按“是否恢复上次记录的执行目标”区分rebalance和change target | 战略锚固定，执行目标可以改变 |

| 增长优势、风险代价和置信区间挤在长段落里 | 用一段说明增长与风险，再用表格列配对区间 | 保留不利结果和完整区间，减少阅读负担 |
| 同一限制在数段和图注重复 | 图注解释读图，正文解释结果；删除解释的再解释 | 避免为“严谨”反复附加相同免责声明 |

## 统一术语

| 英文术语 | 本稿含义 | 避免混用 |
| --- | --- | --- |
| Balanced A | 冻结的`plan_a_balanced`完整策略 | 不等同于固定50/35/15基准 |
| strategic anchor | 按期限冻结的战略权重 | 不与可变execution target互换 |
| real CAGR / $G$ | 扣费后实际复合年增长率 | 不写成算术平均收益 |
| maximum real drawdown / $D$ | 单路径实际财富最大回撤 | 不与终值亏损、波动率混用 |
| P90 drawdown | 60条路径回撤的90分位数 | 不称为损失上限或置信区间 |
| drawdown CVaR90 | 最差10%回撤的平均值 | 不等于战略优化的对数回撤ES |
| human review | 停止自动交易，保留已有持仓 | 不暗示已执行止损或顾问干预 |

## 图形来源与复核

本轮使用安装的`nature-figure`和`nature-polishing`，沿用Python/Matplotlib。风险收益图是对现有代码的结构调整，严重案例图根据保存账本重新绘制，未使用其他论文图件或模拟示例。竞赛字号和页数要求优先于Nature期刊的常见尺寸。

- 风险收益图：基础费率0.25%、30年、六个已列明策略，每点汇总同一组60条路径；其他期限和费率不属于该图的问题范围。
- 严重案例：从完整保存账本按策略、场景155、30年和基础费率筛出恰好30条年度记录，逐项验证峰谷、终值、复核年份和交易数。起点100来自账户定义；没有重新读取市场、运行策略或拟合模型。
- 来源CSV随生成资产保存，列名和数值维持原始小数口径；图中收益和回撤乘100显示为百分数。
- 原有费用敏感性曲线保留，统一补充SVG与300dpi预览，数值及第6节文字不变。
- 三图均导出可编辑PDF/SVG和PNG预览，逐图执行Nature字体与碰撞检查；费用双面板另做最终绘图区几何检查，容差1.5pt。
- 静态预检的三项提示已核对：主稿嵌入矢量PDF，不需TIFF；PNG仅作300dpi预览；约171mm宽度按A4正文宽度设计，并非Nature期刊的89/183mm规格。
