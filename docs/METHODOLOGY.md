# 建模与指标定义

本文件合并原建模概览与数学说明，是模型假设和指标公式的唯一维护位置。接口见 [INTERFACES.md](INTERFACES.md)，选择与统计程序见 [PROTOCOL.md](PROTOCOL.md)，结果见 [FINDINGS.md](FINDINGS.md)。

## 依据与数据边界

以提供的 [题目 PDF](../2026_MCM_SafeInvest.pdf) 第 1–2 页为准；[英文提取文本](problem.txt) 仅为检索副本。题目要求购买力增长、普通波动和大损失指标，但没有规定具体公式或综合评分。采用实际 CAGR、年度收益样本标准差和最大回撤，是本项目的选择。

开发只使用情景 1–120，即 3,600 个年度观测、**120 个独立抽样单位**，不能把 3,600 行当成独立试验。开发加载器只解析有序 CSV 的前 3,600 行并验证情景/年度键。系统缓冲可能读入边界后的字节，因此这是分析层的数据隔离，不是文件系统权限隔离；由独立成员保管最终数据更可靠。

本轮基准工作未解析、拟合、汇总或哈希情景 121–180。项目初始化时已有全文件校验/hash，属于历史数据格式操作，不能称为独立最终评价。字段和许可见 [DATA.md](DATA.md)。

## 年度时序与交易核算

资产顺序为 equity、bond、bill，收益及费用均为小数。每条路径初始名义/实际财富均为 100，全持有 bills；没有后续存取款、税费、其他费用或终值清算费。bill 代理资产的实际收益可能为负，不能当成购买力无风险资产。

第 t 年开始时，策略仅收到截至 t−1 的市场历史、现有持仓、目标权重、累计通胀、实际财富峰值、费用率和复核状态。它不能收到完整评价情景或当年/未来收益。初始建仓在第 1 年收益之前完成，收费一次。

对交易前持仓 h、财富 V=Σhᵢ、漂移权重 pᵢ=hᵢ/V、目标 w 和费用率 c：

```text
Q = (V/2) Σ|wᵢ − pᵢ|             转移金额，只计一次
F = cQ                           当期费用
hᵢ⁺ = (V − F)wᵢ                 扣费后持仓
hᵢ,end = hᵢ⁺(1 + rᵢ,t)          年末名义持仓
Iₜ = ∏ₖ≤ₜ(1 + πₖ)                累计通胀
Wₜ = Σhᵢ,end / Iₜ                年末实际财富
```

Q 按扣费前目标计算，费用按目标持仓比例支付。这是对题目未指定细节的明确解释，与项目核算约定一致；不是另求一个扣费后美元头寸严格满足目标的隐式自融资解。例：100 bills 转成 20% equity，Q=20、F=0.05，扣费后持仓为 `(19.99,0,79.96)`；三等分建仓费为 1/6。年度记录已包含建仓费，不能再额外累加。

所有持仓始终只做多、满仓。Balanced 优化目标另加研究边界：equity 20%–65%、bond 10%–70%、bill 10%–60%，它们不是题目约束。持有期间自然漂移可以离开该范围，因此“目标上限”不等于“持续敞口上限”。不同可行域的比较也不只是估计器优劣比较。

## 评价指标

令 W₀=100，期限为 H，年度净实际收益 aₜ=Wₜ/Wₜ₋₁−1。

| 指标 | 数学定义与解释 |
| --- | --- |
| 实际 CAGR | G=(W_H/100)^(1/H)−1，含全部费用 |
| 普通波动 | σ=√[Σ(aₜ−ā)²/(H−1)]；H=1 在解析测试中定义为 0，正式实验 H≥5 |
| 实际最大回撤 | D=maxⱼ[1−Zⱼ/maxₖ≤ⱼZₖ]；Z 按时间排列初始、**每次扣费后/收益前**及各年末实际财富 |
| 后续交易率 | 第 2..H 年 Qₜ>10⁻¹⁰×初始财富的次数除以 H−1；另导出含建仓的交易率 |
| 名义/实际费用 | ΣFₜ / Σ(Fₜ/Iₜ₋₁)；实际费用以初始购买力计，不是终值机会损失 |
| 平均换手 | H⁻¹Σ(Qₜ/Vₜ)，包含建仓 |
| 最差年度收益 | min aₜ |
| 终值损失概率 | 跨情景估计 P(W_H<100) |
| 复核率 | 至少触发一次人工复核的情景比例；另记录首次触发年 |

D 越大表示损失越严重，包含可能在当年恢复的费用损失，但无法观测未知的年内市场回撤。复核动作本身不证明避免了损失，也不代表顾问干预成功。费用已计入财富，不能在净 CAGR 上重复扣减。

每个策略/期限/成本分别报告中位 G、P10 G、中位 D、P90 D，以及中位 σ、平均交易率等。分位数按排序后 `(n−1)p` 线性插值。先逐情景计算，再跨情景聚合；同一路径的多个期限不能作为独立样本。

辅助指标 CVaR90(D) 为最坏 10% 情景回撤的均值，边界采用分数样本质量。对年度损失 ℓ=−wᵀr_real：

```text
CVaRα = min_z {z + mean[max(ℓ−z, 0)]/(1−α)}
```

这一定义对应精确经验分布的上尾均值，不是简单取大于线性插值分位点的观测均值。每条路径还导出年度实际收益损失的 CVaR90；其跨情景中位数不等于池化所有年份后的 CVaR。

## 拟合、优化和收益门槛

学习量只由训练折估计。所有训练情景等长，因此池化年份仍给每条情景相同权重。使用独立训练情景的全部 30 年是离线学习，不等于历史时间顺序回测；池化隐含无条件分布足够稳定的假设。

协方差为 `.75S + .25diag(S) + 10⁻¹⁰I`。这是固定对角收缩，不是数据驱动的 Ledoit–Wolf 估计器。均值方差和最小方差采用 SLSQP，求解失败明确报错。CVaR 在预声明的 5 个百分点网格上穷举，对该离散网格精确，不能宣称连续全局最优；不可行则中止，不能以替代组合伪装满足约束。

初版在 Balanced 边界内要求 CVaR≤8%，所有外层折不可行。修正保留 8% 上限，让防御型 CVaR 参照使用题目允许的完整单纯形；失败版本保留标记，不能用于约束成立的结论。

自适应均值使用此前最多 5 年：`μₜ=(30μ_train+Σr_recent)/(30+n_recent)`，协方差固定。这是透明的收缩启发式，不是已证明有效的预测模型，也不是指定似然后的贝叶斯后验。

定义一年期风险调整总价值代理：

```text
A(w) = 1 + μₜᵀw − γwᵀΣw/2
f = c Σ|w−p|/2
B = [A(w)−A(p)]/A(w)
```

选择 `(1−f)A(w)` 最大的网格目标，仅当 `B>f+buffer` 才交易。对选定代理，这是明确的改进判据；它不是精确期望效用定理或实际收益保证。引擎独立重算 f 并拒绝错误门槛。保持现有持仓始终是可选动作；初始建仓由入门配置决定，豁免后续自由交易门槛。

## 人工复核与客户适配

人工复核在年度决策时已观察实际回撤≥25%触发。第 t 年只能基于截至 t−1 的损失，不能提前使用第 t 年损失。复核待处理期间保持资产并继续估值，暂停自动交易，不虚构顾问干预。这不是止损保证，年度复核之间仍可能发生崩跌。

Conservative/Balanced/Growth 使用上述固定配置，按 A=5、B=15、C=30、D=25、E=6 年计算风险。对每个候选统计 MDD 超过客户自述容忍度的 k/n，以 `1−.05/3` 置信水平计算一侧 Clopper–Pearson 上界，对单个客户的三种选择做同时保护。只有上界≤20%才通过风险筛选。

20% 是服务风险假设，不是官方要求、保证或已经校准的客户偏好。高流动性只允许 Conservative，Growth 至少需要 15 年；合格者选中位实际 CAGR 最高者，否则转人工。没有提款计划，流动性只是透明规则，不是资产负债模拟。上述风险表评估年度固定目标组合，不能替代对实际自适应建议策略的期限风险验证。

## 2026-10-16：轻量专家与强化学习研究

新增五个候选，全部从50/35/15的Balanced配置建仓。三专家动作是：保持当前漂移持仓（patience）、恢复50/35/15（strategic）、配置20/30/50（defensive）。这是三个可解释的投资政策专家，不是三个大型预测网络，也不是随意切换客户的入门类别。目标属于既有Balanced边界；持有漂移仍可能越界，不承诺持续硬敞口上限。

所有候选共享独立执行门槛。使用既有一年均值方差代理 `A(w)`，但风险系数为 `gamma = gamma_base + 40×当前实际回撤 + 12/剩余年数`，v1的`gamma_base=8`；查看v1后单因素v2改为3，其他系数不变，各轮开始前登记。仅当 `B > 费用比例 + 0.001` 时允许专家交易，保持始终可选。门槛是可核验的风险调整代理，不是预期收益保证；RL价值不充当交易收益估计。

- `expert_defensive`：在防御交易通过门槛时选择防御，否则保持。
- `expert_greedy`：在已通过门槛的战略、防御与保持之间，选择扣费代理最高者。
- `moe_supervised`：原专家v1/v2为11维状态→12→8→3；当前补齐历史最大回撤后为12维输入的tanh网络，输出三个专家概率，非法交易概率屏蔽；三个固定种子概率平均后取最大值，属于硬门控MoE。
- `moe_rl`：以上监督网络初始化后使用REINFORCE继续优化多期目标，评价时仍使用三个固定种子的概率集成和确定性最大概率动作。
- `moe_rl_static`：仅有三个可训练logit的RL门控，检验是否需要学习状态表示。**执行门槛仍依赖状态**，因此不是完全固定的投资策略。

当前状态为三资产当前权重、已观察实际回撤、历史最大实际回撤、相对初始购买力的对数财富、剩余年数/30、期限/30、过去最多5年的权益/债券实际收益均值、通胀均值和权益普通波动（总体标准差）。没有情景ID、当前或未来收益。均值方差估计与状态标准化仅使用当前训练折；标准差下限0.001，标准化输入截断至[-8,8]。

监督标签：在训练折各期限下由随机合法专家行为生成状态，用**该训练路径**下一年实现的净对数收益/期限减最大回撤增量惩罚，确定一步最佳合法动作。标签可以用训练结果，但评价决策不能用未来；这是高噪声的监督初始化，不声称拥有真实市场状态标签。

RL每轮在当前训练情景上随机抽取预声明期限，采样合法专家，使用未折扣回报到达项和同期限/时点的留一均值基线。优化目标：`E[log(W_H/W_0)/H - lambda×MDD]`，其中`lambda∈{0.1,0.3}`；奖励分解为每期净对数收益/期限减最大回撤增量惩罚。费用已在财富中扣除，不重复扣减。初始费用的共同常数纳入训练目标诊断；初始建仓不由门控学习。熵奖励0.01、Adam步长0.003、监督80轮、RL120轮，固定三种子101/202/303；不根据评价结果早停、选种子或扩展网络。

监督和RL均用NumPy实现，梯度经有限差分检查；训练向量化模拟器与原有标量引擎按不同期限逐一验证财富和含扣费时点的最大回撤。重放市场路径不会创造新的独立市场信息。训练目标的期望回撤惩罚也不等于P90风险保证，最终判断依赖整情景折外评价。

## 方法来源

- DeMiguel、Garlappi 与 Uppal（2009）：[Optimal Versus Naive Diversification](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=1376199)。支持认真设置 1/N 比较，以及对估计复杂度带来的收益保持审慎；其历史市场结论不能直接套用到本数据。
- Ledoit 与 Wolf：[Honey, I Shrunk the Sample Covariance Matrix](https://econ-papers.upf.edu/papers/691.pdf)。支持协方差正则化；本项目采用更简单的固定对角收缩。
- Rockafellar 与 Uryasev：[Optimization of Conditional Value-at-Risk](https://sites.math.washington.edu/~rtr/papers/rtr179-CVaR1.pdf)。经验 CVaR 的数学依据；本项目采用离散网格优化。
- Cawley 与 Talbot（2010）：[On Over-fitting in Model Selection and Subsequent Selection Bias](https://www.jmlr.org/beta/papers/v11/cawley10a.html)。支持嵌套选择及对重复使用开发集的偏差限制。

外部研究只用于方法设计；未引入外部金融收益或最终留出数据进行开发。

## 路径风险预算与情景价值规划

提交版研究将风险预算直接定义在含交易成本的实际财富路径上。对每个训练期限H和候选权重，完整模拟年度再平衡，计算实际CAGR、P10增长及跨情景最大回撤的90%尾均值。该指标是最大回撤分布的尾均值，与单条路径所有水下时点的CDaR不同。选取满足相对于等权尾部预算和P10约束的最高中位增长配置；无可行解时明确记录违约。

多期规划器在每次决策比较保持当前权重、恢复战略权重、切到防御权重。未来路径全部来自该层训练集，假定跨情景路径前缀可代表剩余期限；每个候选在规划期内买入并持有，下一次真实决策再规划。价值为预期`log(W_H/W_now)/H`减回撤惩罚乘未来累计最大回撤的90%尾均增量，已包含立即交易费用。它是有限候选、固定续行假设下的情景规划，不是连续最优控制或完美预测。

令净价值差为ΔQ，立即费用比例为f。采用风险调整确定性等价收益`benefit = 1 − (1−f) exp(−H ΔQ)`；只有`benefit > f + buffer`才交易，引擎独立复核f。故不能把此收益估计解释为保证盈利。短期对照仅预测一步，线性/神经对照学习同一规划器的动作价值差；费用敏感性中近似模型仅精确修正立即费用的对数财富项，风险部分为近似，须与精确规划对照。

设计参考：Boyd等《Multi-Period Trading via Convex Optimization》(2017)，https://arxiv.org/abs/1705.00109；Chekhlov、Uryasev、Zabarankin《Drawdown Measure in Portfolio Optimization》(2005)，https://www.math.columbia.edu/~chekhlov/IJTheoreticalAppliedFinance.8.1.2005.pdf。本项目采用复利实际财富及离散候选情景计算，不直接套用其线性/凸性结论。数学建模skill仅提供问题适配与算法参考，所有约束、核算和最终结论以题目和本项目核验为准。

第二批将训练配置约束与Balanced主比较对齐：训练P90最大回撤需比固定Balanced至少低3或5个百分点，P10增长损失不超过0.2个百分点。选择的是有限训练样本上的配置，实际动态策略仍需独立外层评价。每个动作价值加入固定超额风险惩罚：与同状态战略动作相比，预测P90回撤超出1个百分点的部分乘0.5后扣除。这个风险违约项是建模偏好，不是官方评分或真实最大损失保证。两组回撤惩罚降为0.01和0.03，检验第一批过度防御问题；没有放宽外层晋级条件。

## 细网格与购买力缓冲风险偏好

令实际财富为W、历史实际财富峰值P、当前回撤d=1−W/P，选择研究预算L并定义参考财富F=(1−L)P。对缓冲财富C=W−F>0采用幂效用，其相对缓冲财富的风险厌恶设为a=4L；相对总财富的局部风险厌恶为`gamma=−W u''(C)/u'(C)=4L W/C=4L(1−d)/(L−d)`。这给出财富峰值gamma=4、随回撤平滑上升的结构。实际实现将d截断到L−0.02，避免预算附近的奇异性和预算越界后风险厌恶反向下降。

交易仍使用明确声明的局部均值方差代理`A(w)=1+mu·w−gamma wΣw/2`；它是效用近似，不是精确的幂效用期望。比较当前持仓、现有目标与2.5%细网格目标，选择扣费代理最高且收益超过精确费用及0.0001余量的动作。静态对照始终gamma=4，初始配置均为50/35/15，因而避免配置变化混淆动态风险偏好的作用。

F是风险偏好的参考值，不是受保护的购买力底线：bills也可能因通胀损失实际价值，年度跳跃和费用会越过参考值。真实服务在严重回撤或估计失效时转人工；等待期间保持现有资产，不虚构保护效果。收益和风险是否改善仍由完整外层路径评价决定。

战略锚定变体：用逆优化构造`mu_prior=gamma0 Sigma w_B + s 1`，其中` s=mu_train·w_B−gamma0 w_BΣw_B`，使Balanced在gamma0下满足完全投资一阶最优条件，并保持其训练期望收益水平。正定协方差下这是摩擦前严格凹代理的最优配置；不等于市场均衡已被数据证明。此处只借用逆优化先验思想，不是含投资者观点后验的完整Black-Litterman模型。参考官方实现说明：https://www.mathworks.com/help/finance/black-litterman-portfolio-optimization.html 。动态反馈改为`gamma=gamma0[1+0.5(ratio−1)]`，检验减弱回撤反应是否改善增长/风险取舍；所有结论仍依赖折外路径评价。
