# 建模与指标定义

本文件合并原建模概览与数学说明，是模型假设和指标公式的唯一维护位置。接口见 [INTERFACES.md](INTERFACES.md)，选择与统计程序见 [PROTOCOL.md](PROTOCOL.md)，结果见 [FINDINGS.md](FINDINGS.md)。

## 依据与数据边界

以提供的 [题目 PDF](../2026_MCM_SafeInvest.pdf) 第 1–2 页为准；[英文提取文本](problem.txt) 仅为检索副本。题目要求购买力增长、普通波动和大损失指标，但没有规定具体公式或综合评分。采用实际 CAGR、年度收益样本标准差和最大回撤，是本项目的选择。

开发只使用情景 1–120，即 3,600 个年度观测、**120 个独立抽样单位**，不能把 3,600 行当成独立试验。开发加载器只解析有序 CSV 的前 3,600 行并验证情景/年度键。系统缓冲可能读入边界后的字节，因此这是分析层的数据隔离，不是文件系统权限隔离；由独立成员保管最终数据更可靠。

本轮基准工作未解析、拟合、汇总或哈希情景 121–180。项目初始化时已有全文件校验/hash，属于历史数据格式操作，不能称为独立最终评价。字段和许可见 [DATA.md](DATA.md)。

## 年度时序与交易核算

资产顺序为 equity、bond、bill，收益及费用均为小数。每条路径初始名义/实际财富均为 100，全持有 bills；没有后续存取款、税费、其他费用或终值清算费。bill 代理资产的实际收益可能为负，不能当成购买力无风险资产。

第 t 年开始时，策略仅收到截至 t−1 的市场历史、现有持仓、目标权重、累计通胀、实际财富峰值、费用率和复核状态。它不能收到完整评价情景或当年/未来收益。初始建仓在第 1 年收益之前完成，收费一次。

对交易前持仓 h、财富 V=Σhᵢ、漂移权重 pᵢ=hᵢ/V、目标 w 和费用率 c：

```text
Q = (V/2) Σ|wᵢ − pᵢ|             转移金额，只计一次
F = cQ                           当期费用
hᵢ⁺ = (V − F)wᵢ                 扣费后持仓
hᵢ,end = hᵢ⁺(1 + rᵢ,t)          年末名义持仓
Iₜ = ∏ₖ≤ₜ(1 + πₖ)                累计通胀
Wₜ = Σhᵢ,end / Iₜ                年末实际财富
```

Q 按扣费前目标计算，费用按目标持仓比例支付。这是对题目未指定细节的明确解释，与项目核算约定一致；不是另求一个扣费后美元头寸严格满足目标的隐式自融资解。例：100 bills 转成 20% equity，Q=20、F=0.05，扣费后持仓为 `(19.99,0,79.96)`；三等分建仓费为 1/6。年度记录已包含建仓费，不能再额外累加。

所有持仓始终只做多、满仓。原Benchmark的Balanced优化另加研究边界：equity 20%–65%、bond 10%–70%、bill 10%–60%，它们不是题目约束。计划A使用完整单纯形，保守产品另设战略bill下限40%。持有期间自然漂移可以离开目标范围，因此“目标上限/下限”不等于“持续敞口约束”。不同可行域的比较也不只是估计器优劣比较。

## 评价指标

令 W₀=100，期限为 H，年度净实际收益 aₜ=Wₜ/Wₜ₋₁−1。

| 指标 | 数学定义与解释 |
| --- | --- |
| 实际 CAGR | G=(W_H/100)^(1/H)−1，含全部费用 |
| 普通波动 | σ=√[Σ(aₜ−ā)²/(H−1)]；H=1 在解析测试中定义为 0，正式实验 H≥5 |
| 实际最大回撤 | D=maxⱼ[1−Zⱼ/maxₖ≤ⱼZₖ]；Z 按时间排列初始、**每次扣费后/收益前**及各年末实际财富 |
| 后续交易率 | 第 2..H 年 Qₜ>10⁻¹⁰×初始财富的次数除以 H−1；另导出含建仓的交易率 |
| 名义/实际费用 | ΣFₜ / Σ(Fₜ/Iₜ₋₁)；实际费用以初始购买力计，不是终值机会损失 |
| 平均换手 | H⁻¹Σ(Qₜ/Vₜ)，包含建仓 |
| 最差年度收益 | min aₜ |
| 终值损失概率 | 跨情景估计 P(W_H<100) |
| 复核率 | 至少触发一次人工复核的情景比例；另记录首次触发年 |

D 越大表示损失越严重，包含可能在当年恢复的费用损失，但无法观测未知的年内市场回撤。复核动作本身不证明避免了损失，也不代表顾问干预成功。费用已计入财富，不能在净 CAGR 上重复扣减。

每个策略/期限/成本分别报告中位 G、P10 G、中位 D、P90 D，以及中位 σ、平均交易率等。分位数按排序后 `(n−1)p` 线性插值。先逐情景计算，再跨情景聚合；同一路径的多个期限不能作为独立样本。

辅助指标 CVaR90(D) 为最坏 10% 情景回撤的均值，边界采用分数样本质量。对年度损失 ℓ=−wᵀr_real：

```text
CVaRα = min_z {z + mean[max(ℓ−z, 0)]/(1−α)}
```

这一定义对应精确经验分布的上尾均值，不是简单取大于线性插值分位点的观测均值。每条路径还导出年度实际收益损失的 CVaR90；其跨情景中位数不等于池化所有年份后的 CVaR。

## 拟合、优化和收益门槛

学习量只由训练折估计。所有训练情景等长，因此池化年份仍给每条情景相同权重。使用独立训练情景的全部 30 年是离线学习，不等于历史时间顺序回测；池化隐含无条件分布足够稳定的假设。

协方差为 `.75S + .25diag(S) + 10⁻¹⁰I`。这是固定对角收缩，不是数据驱动的 Ledoit–Wolf 估计器。均值方差和最小方差采用 SLSQP，求解失败明确报错。CVaR 在预声明的 5 个百分点网格上穷举，对该离散网格精确，不能宣称连续全局最优；不可行则中止，不能以替代组合伪装满足约束。

初版在 Balanced 边界内要求 CVaR≤8%，所有外层折不可行。修正保留 8% 上限，让防御型 CVaR 参照使用题目允许的完整单纯形；失败版本保留标记，不能用于约束成立的结论。

自适应均值使用此前最多 5 年：`μₜ=(30μ_train+Σr_recent)/(30+n_recent)`，协方差固定。这是透明的收缩启发式，不是已证明有效的预测模型，也不是指定似然后的贝叶斯后验。

定义一年期风险调整总价值代理：

```text
A(w) = 1 + μₜᵀw − γwᵀΣw/2
f = c Σ|w−p|/2
B = [A(w)−A(p)]/A(w)
```

选择 `(1−f)A(w)` 最大的网格目标，仅当 `B>f+buffer` 才交易。对选定代理，这是明确的改进判据；它不是精确期望效用定理或实际收益保证。引擎独立重算 f 并拒绝错误门槛。保持现有持仓始终是可选动作；初始建仓由入门配置决定，豁免后续自由交易门槛。

## 计划A：路径风险配置与部分再平衡

该扩展同时连接三类产品、客户期限、实际执行和复核。下述参数均在`development_plan_a_v1`运行前登记，研究取值不代表题目规定。

对每条训练路径，固定年度权重w的最大对数回撤为：

```text
Y_s(w) = max_{0≤u≤v≤H} {−Σ[t=u+1..v] log(1+r_real(s,t)ᵀw)}
minimize  −mean[s,t] log(1+r_real(s,t)ᵀw)
subject to CVaR90(Y(w)) ≤ b, w≥0, Σw=1
```

空区间允许零回撤。负对数凸，区间求和、最大值及经验上尾均值保持凸性，故无费用、固定年度权重的战略子问题是凸问题。CVaR作用于每条路径的最大对数回撤，不是池化年度损失或所有时点回撤。普通最大回撤为`1−exp(−Y)`，但不能把非线性变换移到CVaR之外当成等式。

以原Conservative/Balanced/Growth配置在相同训练样本、相同H上的对数回撤CVaR90作为参照预算，分别乘0.9或1.0；保守产品附加bill目标下限40%。不保证样本外风险顺序，更不保证客户容忍度。三个产品的实际期限风险仍须独立筛选。

连续求解采用Kelley切平面：对负对数增长目标及风险函数逐次加入全局支撑超平面，LP松弛给目标下界，可行权重给上界，间隙≤1e−6停止，风险允许数值误差1e−8，最多300轮。231点5%网格提供初始可行解与目标比较。不可行、LP失败或超过迭代上限明确中止。保存LP约束、原始解和对偶乘子，可独立检查可行残差、对偶平衡及上下界。该证书只针对训练战略子问题。

执行层使用战略锚w*及训练收缩协方差Σ：

```text
A(w) = 1 + mu_trainᵀw* − gamma/2 × (w−w*)ᵀΣ(w−w*)
w(lambda) = p + lambda × (w*−p), lambda ∈ {0,.25,.5,.75,1}
score = (1 − c||w(lambda)−p||₁/2) × A(w(lambda))
```

这是把战略配置作为最优点的偏好代理；偏离锚定配置受到惩罚，不是预测偏离配置必然获得较低收益。gamma从4/12中内层选择，buffer为0.0001；沿用上述B与费用的严格门槛。保持动作始终参与，A非正或失效转人工。部分调整可改变当前执行目标，战略锚不随漂移改变。

主要策略为`plan_a_conservative/balanced/growth`。Balanced的5个对照继承同一内层选择参数与战略锚：每年恢复、持有、完全恢复门控、只回到5%边界、部分门控但取消复核。年度与边界是无门槛诊断；完全门控和无复核部分门控均不启用复核，二者可隔离部分交易的作用；主候选对无复核版本隔离复核作用。

复核阈值为相应训练锚含费用年度策略P90回撤的1.5倍，截到[10%,75%]。阈值仅由训练样本确定，触发基于已观察损失；待复核保持持仓。无费用配置的风险可行性不会自动传递到实际交易路径，因此内层选择额外检查含费用执行的每个期限风险、收益损失和复核率，详见实验协议。

计划A开启时，客户适配直接使用三条实际门控执行策略的OOF结果，并保存实际`policy`。原有流动性/期限/越界上界规则仍适用。OOF训练折重叠，其二项上界只能作为诊断筛选，不能给予全样本重拟合策略严格覆盖保证；40%bill目标也不是提款能力保证。

### 第二轮的风险预算校准

原产品配置w_ref、训练样本T和期限H确定参照`R_ref=CVaR90(Y_T(w_ref))`。第二轮固定验证目标`b_valid=R_ref`，训练战略预算`b_train=q×R_ref`，q只从0.75/0.85/0.95中内层选择；执行风险限额为`b_valid+0.005`，不随q移动。拟合时先解训练预算，再在内层验证含费、部分再平衡和复核的完整路径。这为样本误差与执行偏差留出研究性的安全余量，不对外推风险作保证。

预算低于该训练样本可达到的最小风险时，LP松弛不可行证明对应凸战略问题不可行；保存证据并排除候选。不能用全bill、最小风险配置或更宽预算冒充原预算的解。若全部候选不可执行则终止；若可执行但完整风险筛选均失败，保留最小违约的研究结果并明确标记不合格。

诊断区分四个量：训练无费固定再平衡风险、训练含费年度风险、训练完整执行风险、验证完整执行风险。前两者差反映费用口径影响，第二与第三差反映执行规则影响，第三与第四差包含样本和估计偏差。小验证折的尾部样本很少，该分解是机制诊断，不是严格的误差归因估计。

## 原Benchmark的人工复核与客户适配

人工复核在年度决策时已观察实际回撤≥25%触发。第 t 年只能基于截至 t−1 的损失，不能提前使用第 t 年损失。复核待处理期间保持资产并继续估值，暂停自动交易，不虚构顾问干预。这不是止损保证，年度复核之间仍可能发生崩跌。

Conservative/Balanced/Growth 使用上述固定配置，按 A=5、B=15、C=30、D=25、E=6 年计算风险。对每个候选统计 MDD 超过客户自述容忍度的 k/n，以 `1−.05/3` 置信水平计算一侧 Clopper–Pearson 上界，对单个客户的三种选择做同时保护。只有上界≤20%才通过风险筛选。

20% 是服务风险假设，不是官方要求、保证或已经校准的客户偏好。高流动性只允许 Conservative，Growth 至少需要 15 年；合格者选中位实际 CAGR 最高者，否则转人工。没有提款计划，流动性只是透明规则，不是资产负债模拟。上述风险表评估年度固定目标组合，不能替代对实际自适应建议策略的期限风险验证。

## 低换手融合与固定估值扩展

融合研究保留A战略锚、建议器和人工复核。候选包括保持、战略锚、A建议、训练防御目标及Cai回撤反馈目标；每个后续候选先限制`0.5*||w-current||_1<=0.10`，再按实际限幅后的动作估值。短期H≤6直接执行原A，初始建仓仍为同一战略锚且正常扣费。未来库仅取对应训练情景的同年度后缀，保留资产联合变化及年度顺序。

令`V_a`为当前实际财富归一为1后的终点净财富，`D_a`为包括历史峰值、历史最大回撤、各次扣费标记的整段最大实际回撤；`a=0`为当前保持，`a=1`为限幅战略锚。原融合价值为：

```text
Q_a = mean(log(V_a))/H
      - 0.03 * (ES90(D_a) - historical_MDD)
      - 0.5 * max(0, P90(D_a) - P90(D_1) - 0.01)
benefit_a = fee_a + (1-fee_a) * (1-exp(-H*(Q_a-Q_0)))
```

时间尺度始终为客户原始H，不随剩余期限改写。非保持动作必须满足`benefit_a > fee_a + 0.02`，然后在合格动作中按Q取最大；无合格者保持。这里的ES作用于原始MDD，而A内层固定约束作用于`-log(1-MDD)`，两者不能混称同一风险量。2%是模型确定性等价净改善门槛，不是年化收益保证；该风险偏好也不是官方评分。

原融合在每个候选后假定持有到期。固定的含费A延续扩展改为：执行当前候选后，未来每年依据同一训练A模型调整，逐次扣费并更新实际峰值/最大回撤；触发复核后持续保持。该延续是实际年度融合决策的近似。当前保持候选也采用相同的未来A延续，首步交易费用仍只计一次；后续费用进入终点财富和回撤，不另从Q重复减去。实际外层交易继续遵守10%限幅及2%门槛。

固定的不确定性扩展保留持有延续，对训练情景进行200次整路径等概率有放回重采样（seed20261021），每次重新计算Q中的均值、ES、P90及屏障。定义`sd_a=sample_sd(Q_a_boot-Q_0_boot)`，以`Q_a_adjusted=Q_a-sd_a`代入上述排名和benefit公式，保持动作的sd为0。系数固定1，锚与训练模型不在bootstrap内重拟合。这是条件于已拟合模型的不确定性惩罚，不是完整模型置信区间；它可能推迟有效减仓。计数加权计算ES及线性分位数与显式重复情景精确等价，生成数据测试逐一比较。

三期限长期参数必须按部署程序的实际路径重新校准。降低训练风险比例可能改变初始配置，因此同时保留各自同锚A、年度和持有对照，不能把配置变化全部归于交易时机。选择、费用保护及停止条件在实验前登记；本节算法不产生未来风险上限保证。

## 方法来源

- DeMiguel、Garlappi 与 Uppal（2009）：[Optimal Versus Naive Diversification](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=1376199)。支持认真设置 1/N 比较，以及对估计复杂度带来的收益保持审慎；其历史市场结论不能直接套用到本数据。
- Ledoit 与 Wolf：[Honey, I Shrunk the Sample Covariance Matrix](https://econ-papers.upf.edu/papers/691.pdf)。支持协方差正则化；本项目采用更简单的固定对角收缩。
- Rockafellar 与 Uryasev：[Optimization of Conditional Value-at-Risk](https://sites.math.washington.edu/~rtr/papers/rtr179-CVaR1.pdf)。经验 CVaR 的数学依据；本项目采用离散网格优化。
- Cawley 与 Talbot（2010）：[On Over-fitting in Model Selection and Subsequent Selection Bias](https://www.jmlr.org/beta/papers/v11/cawley10a.html)。支持嵌套选择及对重复使用开发集的偏差限制。

外部研究只用于方法设计；未引入外部金融收益或最终留出数据进行开发。

## 计划B：固定战略偏好上的因果收益倾斜

只使用训练情景年3–30拟合股票实际收益减bills实际收益，输入为过去最多五年的12项特征。训练集标准化、未惩罚截距、固定Ridge系数10；目标期均值与预测相减得到`delta`。验证、实际逐时及冻结模型均不重新标准化或拟合。

同A价值增加`eta * delta * (w_equity - anchor_equity)`，eta限0/.25/.5。A的均值项原本是动作共享常数，直接替换均值不能产生所需的方向倾斜。交易费用仍为费率乘单边换手，动作按`(1-fee)*value`排名，随后执行与A相同的效益大于费用加边际门槛。窄动作eta0严格重现A；宽动作增加锚附近资产对各±5个百分点，需要另设宽动作eta0控制其自身效应。

内层沿用原A选择，再在同训练/验证分区评估B。各族相对自身eta0检查固定风险线、中位/P10增长损失与复核率；可行最高平均对数增长候选的一标准误集合优先较小eta，差值按情景聚合期限后估计标准误。仅时间和每训练路径循环移位7年的标签均为诊断，不作为赢家。内层合格与外层有效性是两项不同结论。

## 计划C：固定情景与动作下的规划深度实验

状态增加历史最大实际回撤，不能仅保留当前财富/峰值；已经恢复的历史回撤仍属于终点路径损失。引擎及预测轨迹都在扣费后与年度末更新峰值/最大回撤。未来情景取当前训练分区全部联合路径同年度后缀，转换成联合实际收益，保持资产、年份及通胀的联动；不按验证路径后续结果选择未来情景。这一版使用未条件化的训练后缀，不声称已学会未来市场状态。

控制动作类型为保持、执行A建议、恢复战略锚和训练231点网格中路径风险最低的年度配置。所有未来情景共享同一动作类型序列，类型执行目标可因当时已实现的资产状态不同而不同；不允许每条路径选择最优未来动作。L1枚举4个序列，L3枚举64个；客户剩余期限不足时缩短。控制段以后统一执行同一A至同一客户终点，A复核为吸收持有状态，实际执行只取第一动作，下一年度重新规划。

评价`J = mean(log(W_terminal_net/W_now)) - kappa * ES90(-log(1-MDD_terminal))`，含全部未来费用，ES精确使用分数尾部质量。kappa1为主，0为删除风险项的诊断。当前保持的参照是“第一步保持后仍允许未来规划”的最佳净价值，避免把主动方案与永远不交易混比。

若第一笔费用比例为f，门槛效益定义为`f + (1-f)*(-expm1(J_hold-J_best))`，与`f + buffer`比较。J本身已扣费；该公式是净价值代理的记账拆分，避免再扣一次费用，不等于真实无费用反事实。当前费用影响回撤的部分仍在J内。该实验仅比较有限动作族和冻结延续策略的控制深度，不宣称全局投资最优、风险约束必然满足或跨时间一致。

主比较为L3对L1，C1对A同时改变动作族和目标，仅作诊断。先完成H30正常/双倍费用开发筛选，只有主比较通过既定增长或风险全部条件才另登记全期限实验；未通过即按预声明停止。客户推荐仍由既有三类A产品诊断，不能从一个H30结果直接向短期客户推荐C。
