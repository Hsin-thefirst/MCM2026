# 建模与指标定义

本文件合并原建模概览与数学说明，是模型假设和指标公式的唯一维护位置。接口见 [INTERFACES.md](INTERFACES.md)，选择与统计程序见 [PROTOCOL.md](PROTOCOL.md)，结果见 [FINDINGS.md](FINDINGS.md)。

## 依据与数据边界

以提供的 [题目 PDF](../2026_MCM_SafeInvest.pdf) 第 1–2 页为准；[英文提取文本](problem.txt) 仅为检索副本。题目要求购买力增长、普通波动和大损失指标，但没有规定具体公式或综合评分。采用实际 CAGR、年度收益样本标准差和最大回撤，是本项目的选择。

开发只使用情景 1–120，即 3,600 个年度观测、**120 个独立抽样单位**，不能把 3,600 行当成独立试验。开发加载器只解析有序 CSV 的前 3,600 行并验证情景/年度键。系统缓冲可能读入边界后的字节，因此这是分析层的数据隔离，不是文件系统权限隔离；由独立成员保管最终数据更可靠。

本轮基准工作未解析、拟合、汇总或哈希情景 121–180。项目初始化时已有全文件校验/hash，属于历史数据格式操作，不能称为独立最终评价。字段和许可见 [DATA.md](DATA.md)。

## 年度时序与交易核算

资产顺序为 equity、bond、bill，收益及费用均为小数。每条路径初始名义/实际财富均为 100，全持有 bills；没有后续存取款、税费、其他费用或终值清算费。bill 代理资产的实际收益可能为负，不能当成购买力无风险资产。

第 t 年开始时，策略仅收到截至 t−1 的市场历史、现有持仓、目标权重、累计通胀、实际财富峰值、费用率和复核状态。它不能收到完整评价情景或当年/未来收益。初始建仓在第 1 年收益之前完成，收费一次。

对交易前持仓 h、财富 V=Σhᵢ、漂移权重 pᵢ=hᵢ/V、目标 w 和费用率 c：

```text
Q = (V/2) Σ|wᵢ − pᵢ|             转移金额，只计一次
F = cQ                           当期费用
hᵢ⁺ = (V − F)wᵢ                 扣费后持仓
hᵢ,end = hᵢ⁺(1 + rᵢ,t)          年末名义持仓
Iₜ = ∏ₖ≤ₜ(1 + πₖ)                累计通胀
Wₜ = Σhᵢ,end / Iₜ                年末实际财富
```

Q 按扣费前目标计算，费用按目标持仓比例支付。这是对题目未指定细节的明确解释，与项目核算约定一致；不是另求一个扣费后美元头寸严格满足目标的隐式自融资解。例：100 bills 转成 20% equity，Q=20、F=0.05，扣费后持仓为 `(19.99,0,79.96)`；三等分建仓费为 1/6。年度记录已包含建仓费，不能再额外累加。

所有持仓始终只做多、满仓。Balanced 优化目标另加研究边界：equity 20%–65%、bond 10%–70%、bill 10%–60%，它们不是题目约束。持有期间自然漂移可以离开该范围，因此“目标上限”不等于“持续敞口上限”。不同可行域的比较也不只是估计器优劣比较。

## 评价指标

令 W₀=100，期限为 H，年度净实际收益 aₜ=Wₜ/Wₜ₋₁−1。

| 指标 | 数学定义与解释 |
| --- | --- |
| 实际 CAGR | G=(W_H/100)^(1/H)−1，含全部费用 |
| 普通波动 | σ=√[Σ(aₜ−ā)²/(H−1)]；H=1 在解析测试中定义为 0，正式实验 H≥5 |
| 实际最大回撤 | D=maxⱼ[1−Zⱼ/maxₖ≤ⱼZₖ]；Z 按时间排列初始、**每次扣费后/收益前**及各年末实际财富 |
| 后续交易率 | 第 2..H 年 Qₜ>10⁻¹⁰×初始财富的次数除以 H−1；另导出含建仓的交易率 |
| 名义/实际费用 | ΣFₜ / Σ(Fₜ/Iₜ₋₁)；实际费用以初始购买力计，不是终值机会损失 |
| 平均换手 | H⁻¹Σ(Qₜ/Vₜ)，包含建仓 |
| 最差年度收益 | min aₜ |
| 终值损失概率 | 跨情景估计 P(W_H<100) |
| 复核率 | 至少触发一次人工复核的情景比例；另记录首次触发年 |

D 越大表示损失越严重，包含可能在当年恢复的费用损失，但无法观测未知的年内市场回撤。复核动作本身不证明避免了损失，也不代表顾问干预成功。费用已计入财富，不能在净 CAGR 上重复扣减。

每个策略/期限/成本分别报告中位 G、P10 G、中位 D、P90 D，以及中位 σ、平均交易率等。分位数按排序后 `(n−1)p` 线性插值。先逐情景计算，再跨情景聚合；同一路径的多个期限不能作为独立样本。

辅助指标 CVaR90(D) 为最坏 10% 情景回撤的均值，边界采用分数样本质量。对年度损失 ℓ=−wᵀr_real：

```text
CVaRα = min_z {z + mean[max(ℓ−z, 0)]/(1−α)}
```

这一定义对应精确经验分布的上尾均值，不是简单取大于线性插值分位点的观测均值。每条路径还导出年度实际收益损失的 CVaR90；其跨情景中位数不等于池化所有年份后的 CVaR。

## 拟合、优化和收益门槛

学习量只由训练折估计。所有训练情景等长，因此池化年份仍给每条情景相同权重。使用独立训练情景的全部 30 年是离线学习，不等于历史时间顺序回测；池化隐含无条件分布足够稳定的假设。

协方差为 `.75S + .25diag(S) + 10⁻¹⁰I`。这是固定对角收缩，不是数据驱动的 Ledoit–Wolf 估计器。均值方差和最小方差采用 SLSQP，求解失败明确报错。CVaR 在预声明的 5 个百分点网格上穷举，对该离散网格精确，不能宣称连续全局最优；不可行则中止，不能以替代组合伪装满足约束。

初版在 Balanced 边界内要求 CVaR≤8%，所有外层折不可行。修正保留 8% 上限，让防御型 CVaR 参照使用题目允许的完整单纯形；失败版本保留标记，不能用于约束成立的结论。

自适应均值使用此前最多 5 年：`μₜ=(30μ_train+Σr_recent)/(30+n_recent)`，协方差固定。这是透明的收缩启发式，不是已证明有效的预测模型，也不是指定似然后的贝叶斯后验。

定义一年期风险调整总价值代理：

```text
A(w) = 1 + μₜᵀw − γwᵀΣw/2
f = c Σ|w−p|/2
B = [A(w)−A(p)]/A(w)
```

选择 `(1−f)A(w)` 最大的网格目标，仅当 `B>f+buffer` 才交易。对选定代理，这是明确的改进判据；它不是精确期望效用定理或实际收益保证。引擎独立重算 f 并拒绝错误门槛。保持现有持仓始终是可选动作；初始建仓由入门配置决定，豁免后续自由交易门槛。

## 路径风险约束的调参改进

新增研究不改变17种策略的动作公式、资产核算或初始配置，只比较内层选择规则。原一年期方差效用可能偏好增长较高但路径回撤更大的参数；新规则先在内层折外完整路径上筛选P90回撤和P10增长，再在可行集使用原效用的一标准误规则。允许误差为1个百分点回撤、0.10个百分点/年增长，参照为同初始Balanced年度再平衡；它们是预声明研究偏好，不是客户问卷的损失承诺。

gamma范围扩大到3/8/16/32，两组选择程序使用相同8组候选，以区分搜索预算和选择约束的影响。gamma增大只影响风险调整代理和成本门槛；它不强制维持权益上限、不提供止损保证。人工复核规则、复核等待时持有行为和客户适配的固定组合假设均保持原定义。具体选择和失败程序见 [PROTOCOL.md](PROTOCOL.md)。

## 人工复核与客户适配

人工复核在年度决策时已观察实际回撤≥25%触发。第 t 年只能基于截至 t−1 的损失，不能提前使用第 t 年损失。复核待处理期间保持资产并继续估值，暂停自动交易，不虚构顾问干预。这不是止损保证，年度复核之间仍可能发生崩跌。

Conservative/Balanced/Growth 使用上述固定配置，按 A=5、B=15、C=30、D=25、E=6 年计算风险。对每个候选统计 MDD 超过客户自述容忍度的 k/n，以 `1−.05/3` 置信水平计算一侧 Clopper–Pearson 上界，对单个客户的三种选择做同时保护。只有上界≤20%才通过风险筛选。

20% 是服务风险假设，不是官方要求、保证或已经校准的客户偏好。高流动性只允许 Conservative，Growth 至少需要 15 年；合格者选中位实际 CAGR 最高者，否则转人工。没有提款计划，流动性只是透明规则，不是资产负债模拟。上述风险表评估年度固定目标组合，不能替代对实际自适应建议策略的期限风险验证。

## 固定目标与情景效用门槛（2026-10-15 预注册候选）

候选已获用户确认并登记为 `development_efficiency`，执行配置见 `configs/efficiency.json`、统计程序见 [PROTOCOL.md](PROTOCOL.md)。新效率路线不改变既有增长晋级标准或历史结论。本赛题有三个子问题；本节只扩展问题二的交易规则，问题一的客户期限适配和问题三的复核等待行为沿用已有定义，后续须重新验证候选策略的适配性。

优先检验固定Balanced目标50/35/15的成本感知再平衡。现有5个百分点阈值参照没有收益门槛；现有固定门控依赖一年期均值方差代理。新候选同时加入漂移带与明确的情景效用估计，检验少交易是否仍能维持年度Balanced参照的增长及路径风险。

### 假设敏感性预检

- 目标配置：长期固定50/35/15与根据收益预测改变目标是两种不同服务设计。先保持同初始、同固定目标，以隔离交易规则的作用；目标固定不意味着实际持仓权重恒定。
- 估值期限：一年便于估计，但可能漏掉恢复配置的多年作用；三年纳入累积购买力风险，但增加分布稳定性假设。因此分别评价一年与三年情景效用门槛，二者使用同预算。三年结果不能提前被称为更优。
- 评价路线：增长提高且下行不恶化，与增长/风险基本不变但交易更少，是不同主张。本轮建议另设效率路线，保留原增长标准；下面的效率界限只是待登记建议，不能用于追认上轮成功。

### 变量、动作与效益估计

令当前漂移权重为p，固定目标为w0=(0.50,0.35,0.15)，偏离d=max|p−w0|。每年先检查已有人工复核条件；未触发时，d≤b直接保持，d>b仅开启交易估值。候选动作是保持p或一次恢复w0。费用比例f=cΣ|w0−p|/2。

只从相应训练折提取长度L的连续年度片段，分别在同一批冲击下计算两个动作后的实际终值因子X(p)、X(w0)。预测分支在初始动作后持有到L年末，不虚构后续交易或顾问干预。所有训练情景等长，每条训练情景赋相同总权重；片段用于估值，不能当作新增独立情景计算评价置信界。

固定研究偏好gamma=5，用常相对风险厌恶的确定性等价因子作为价值代理：

```text
A(w) = [mean(X(w)^(1−gamma))]^(1/(1−gamma))
B = 1 − A(p)/A(w0)
交易条件：d>b 且 B>f+buffer
```

B是在该代理下最高可接受的一次性收费比例，可以与当期财富费用比例f比较。交易后的因子为(1−f)A(w0)，费用不能再从净绩效重复扣减。模型必须验证因子为正且有限；非法估值转人工并按真实等待行为评价。

L为固定滚动估值代理期限，不是客户剩余投资期限，也没有优化未来动作序列，不能称为完整MPC。若以后改为依赖客户剩余期限，须按接口约定逐期限重新实例化模拟。终值效用不等同路径MDD，外层仍用实际路径指标评价；交易带也不是持续敞口硬约束。

### 拟议的小规模实验与验收

固定L∈{1,3}作为两个策略族，各用b∈{0.03,0.05,0.08}、buffer∈{0,0.001}的六组参数；gamma不搜索。沿用5外折/3内折时，共2×6×3×5=180次候选/内折评价。统计估计仅使用该层训练情景，不能从评价情景截取未来片段。保留官方等权、Balanced年度/持有、现有固定门控及阈值参照，主效率参照为同初始Balanced年度再平衡。

已登记的效率标准：中位CAGR及P10 CAGR相对主参照的配对区间下界均不低于−0.001/年，P90 MDD差异区间上界不高于0.01，后续交易率至少降低50%，平均实际费用不增加；翻倍费用后重新检验。具体区间调整、内层选择、不可行处理及预算已在 [PROTOCOL.md](PROTOCOL.md) 固定，已完成结果见 [FINDINGS.md](FINDINGS.md)。效率成立不能写成增长显著提高，更不能据开发结果保证未来表现。

若该方向仍无法满足条件，应报告取舍并收敛策略选择。另一备选是先检验滞后波动/通胀状态能否在整情景交叉验证中预测下一期风险；存在稳定增量后，再预声明少量状态配置。当前没有该信号已有效的证据。

## 更激进的候选路线（2026-10-15，设计讨论，未实施）

重新核对题面第1–2问：官方要求设计三类组合的配置或规则，并允许Balanced客户改变目标配置；50/35/15和既有Balanced优化边界是本项目研究定义。固定目标效率实验只检验交易规则，尚未检验下面的完整动态控制路线。新路线不能追认旧实验成功，也不能把更低权益敞口的效果归因于算法。

优先候选是反事实动作模拟与树模型离线强化学习。在训练折内，利用市场收益不受本项目交易动作影响的设定，让同一个可达持仓状态分别执行保持、恢复Balanced目标和少量事先固定的目标变更，精确扣费并生成后继状态。用拟合Q迭代学习多期价值，必要时蒸馏为浅决策树；这是本项目拟议设计，不是已有实测结论。方法基础参考Ernst等的[Tree-Based Batch Mode Reinforcement Learning](https://jmlr.org/papers/v6/ernst05a.html)。

- 状态只含截至上一年的收益/通胀、持仓、当前和历史最大实际回撤、目标及剩余期限；需要期限输入时同步修改接口并逐期限独立模拟。
- 在训练边界内允许用训练路径的后续收益构造学习目标；评价情景的当年及未来收益不得用于特征、选动作、选参或更新策略。情景ID不得作为预测特征。
- 研究目标可直接惩罚终值增长不足与客户期限内的容忍度越界；交易费用由财富递推扣除，不能在效益门槛中再次扣除同一费用。Q差或效益估计必须说明是否已净费用，实际交易仍须通过可复核的成本门槛。
- 同路径生成的多动作记录不是新增独立样本，训练、调参与统计区间仍按完整情景分组；深模型容量和训练种子也计入搜索预算。模拟中的先知动作只能作为不可执行的诊断参照，不能冒充可实施策略。

另外两条备选为：其一，小型隐状态模型识别市场状态，再用三年滚动优化同时处理预测风险、已有回撤与成本，逐年只执行第一步；参考Nystrup等的[Multi-Period Portfolio Selection with Drawdown Control](https://stanford.edu/~boyd/papers/multiperiod_portfolio_drawdown.html)。其二，在声明的训练情景概率集合内寻找对候选最不利的权重，再优化该最坏分布下的增长/风险取舍，以检验对分布误差的敏感性；参考Sun与Boyd的[Distributional Robust Kelly Gambling](https://stanford.edu/~boyd/papers/robust_kelly.html)。这些文献的目标和假设不同，均不直接提供本项目的MDD或客户适配保证。

执行前先登记新的研究主张、动作集合、搜索/训练预算、约束、参照与失败处理。优先在内层整情景划分下检验滞后状态是否含有可重复的决策增量；无信息时，更复杂控制器也可能只增加估计误差。保留官方等权及同初始、同可行目标的简单参照；已有增长、效率与客户适配结论分别报告，真实最终留出集继续封存。本次仅记录设计，没有新增配置、训练或开发实验。

## 反事实拟合Q迭代的实现口径（2026-10-15）

本轮对应第2问的新动态配置候选，并为第1问输出按客户期限的风险诊断、第3问提供双倍交易成本检验。状态由历史、漂移权重、当前/历史最大实际回撤、费用及复核标志组成；有限剩余期限k通过独立的价值函数进入策略。动作是保持和三个目标30/30/40、50/35/15、60/25/15，三者均在既有研究目标边界内；漂移并非持续敞口约束。

假设预检区分两种解释：将后续已实现收益作为每次决策可读取的信息会产生先知泄漏，予以排除；仅在训练折内用即时收益和下一状态构造Bellman学习目标属于离线学习，评价时只读历史。另一项区别是同一年不同动作不会影响给定市场收益，因此可精确模拟反事实后继，但扩增记录彼此相关，不可增加独立情景数。采取完整情景内外层划分，不随机划分年度记录。

对训练状态s、动作a，实际即期费用比例为f，实际财富/峰值递推包含交易扣费和通胀。令D是历史最大实际回撤、D′是动作后的新最大回撤、τ=0.40，定义费用前即时奖励：

`r_gross = log(V_real_next / V_real_post_trade) − λ·1{D≤τ<D′}`。

费用引起的当期对数财富变化为`log(1−f)`，解析处理，不在回归目标中重复扣除。`G_k(s,a)`拟合`r_gross + V_{k−1}(s′)`，`V_0=0`；`V_k`在通过费用门槛的动作中最大化`G_k+log(1−f)`。因s′已按真实扣费生成，费用对回撤和后续状态的间接影响仍保留。首次越界只惩罚一次；已进入人工复核或当前回撤达25%的状态只允许保持。

部署时用`benefit=1−exp(−(G_k(s,a)−G_k(s,keep)))`作为风险调整价值代理的财富比例表示；仅当`benefit>f+0.001`才允许交易。该代理含学习到的后续控制和风险惩罚，不等同客观收益、置信保证或上轮CRRA确定性等价。费用后状态会受当期费率影响，官方/双倍费用均进入训练特征与模拟，而非仅在事后扣费。

有限训练路径要求剩余观测数≥k；依次训练k=1..29的确定性多输出CART教师（深度4）及学生（深度2）。回归输出编码为保持价值和其余三动作的相对优势乘10，防止共同收益项主导所有分割；该缩放固定，不作结果后调参。每个节点至多检查每特征16个有序分割点、叶至少48条相关状态记录，按平方误差下降选择，深度或叶数限制即停止。学生以相同训练状态上的教师预测为目标拟合；其部署表现独立评价，训练内一致率不能替代折外验证。无需新增软件依赖。

实现按每个H独立初始化与模拟；剩余期限相关策略不能截取H=30路径。每个训练数据集保存状态、四动作后继、即时增长/费用/首次越界和情景/时期来源；教师/学生树、每期目标和平方和、误差与动作一致率全部保存。独立脚本以名义金额标量递推复核反事实，再检查Bellman目标下全部树节点均值、学生蒸馏和部署动作。完整预算、选择与通过标准见[实验协议](PROTOCOL.md)。

代码任务已对应`learning_core.py`（状态、学习及动作）、`learning_study.py`（分组选择、逐期限评价及报告）、`scripts/verify_learning.py`（独立复算）和`tests/test_learning.py`（生成数据验证）。数据图表包括18项风险区间、教师压缩诊断和动作分布；沿用增长/风险散点、成本、严重情景及期限图。不改写既有实验，不声称训练目标τ=40%已覆盖其他客户的个性化偏好。

## 神经网络候选设计（2026-10-16，未实施）

上一轮学生/教师均表现为较高增长点估计和更差P90回撤，且新目标60%上限没有限制持有/复核等待期间的实际权益敞口。因此单纯用神经网络替换Q树不能解决目标与风险控制的矛盾。以下是新的设计候选，不是已经登记或执行的实验，也不保证通过既有筛选。

优先路线为小型端到端策略网络：输入现有因果状态和剩余期限，采用两层、每层16个单元的MLP，输出相对基础配置的小幅调整或风险配置参数。通过含真实转移费用、通胀、历史峰值及人工复核等待的可微路径模拟训练；以实际终值对数增长为目标，将完整期限最大实际回撤的经验CVaR90作为训练约束，并另设相对参照的弱情景增长约束。CVaR在这里针对路径MDD分布，不是单年损失CVaR；两者不能互换。

训练可借鉴[Deep Learning for Portfolio Optimization](https://arxiv.org/abs/2005.13665)直接优化投资策略的思路和[Deep Hedging](https://arxiv.org/abs/1802.03042)在有摩擦路径上训练风险目标的框架，但前者优化Sharpe、后者主要研究衍生品对冲，均不证明本项目的回撤约束有效。路径约束的原始/对偶优化仍可能不可行或收敛失败，须明确记录，不把惩罚项或训练可行性当成折外保证。

第二条路线是神经风险估计加优化层：小型MLP预测各候选动作的未来风险或分位数，再由明确的费用门槛、目标可行域和优化器选择动作。目标单纯形、配置边界等凸约束可参考[可微凸优化层](https://papers.nips.cc/paper_files/paper/2019/hash/9ce3c52fc54362e22053399d3181c638-Abstract.html)实现；完整未来路径MDD不是仅靠一个凸投影就能保证的硬约束，模型风险估计必须在整情景留出上验证。该路线比直接输出权重更便于逐动作解释，但仍依赖尾部预测的有效性。

第三条路线为神经无交易带网络：网络根据历史状态和剩余期限输出带中心/宽度，持仓在带内保持，带外只做必要调整，再执行三资产联合可行域和成本门槛检查。参考[No-Transaction Band Network](https://arxiv.org/abs/2103.01775)的结构设计；原文是对冲模型，其最优性和实验结果不能直接移植到本题三资产投资。此路线主要针对交易效率，仍需单独验证增长与路径风险。

实施边界：只使用1–120；120条情景才是独立样本，年度片段和反事实记录都不能扩充独立样本数。先采用几百至几千参数的网络，固定少量训练种子并报告全部，归一化/早停/约束阈值仅在训练及内层验证边界内确定。随机种子不用于挑选幸运结果。首轮应同时比较同一约束/成本/复核规则下的线性策略、全特征MLP、去除滞后市场特征的MLP，区分约束与非线性模型的增量；暂不扩展Transformer或大规模序列模型搜索。

配置目标投影只保证新目标合法。若保持动作或复核待处理期间继续持有，实际权重仍会漂移；如果把持续敞口限制作为服务要求，就必须明确与年频复核、效益足以覆盖费用和等待持有规则的兼容方式，不能静默强制交易或改变复核行为。神经网络训练中若使用光滑门槛/最大值代理，最终须按实际离散动作和真实MDD重新回测，报告训练/部署差异。当前依赖未包含自动微分框架，实施时再评估并统一更新依赖范围和锁定环境；本次不安装、不训练、不读取新数据。

## 神经路径约束的实施口径（2026-10-16）

本轮对应第2问的动态Balanced政策、第1问的客户期限诊断和第3问的双倍费用检验。关键歧义有两项：若只限制新目标权重，保持/人工复核等待期间仍可能漂移，故本轮明确只声称目标可行；若在训练时取消费用门槛或复核，再在部署时恢复，会评价不同策略，故训练路径保留同样的离散动作分支。网络只在已选择分支内求导，门槛切换处及排序/最大值处可能不可微，不作全局最优承诺。

令历史状态为s、剩余期限为k，先对训练内统计量标准化，网络输出三维logits。目标是`w=softmax(f_theta(s,k))·T`，T三行为20/35/45、50/35/15、50/25/25。新目标长仓满仓且权益20%–50%。线性模型输出logits的参数数为42，完整16×16 tanh网络为547，持仓特征网络为451；实际部署平均预定种子的目标。市场状态含t−1及更早的三资产实际收益、通胀和近三年权益收益均值/波动，不含评价未来或情景编号。

每次交易仍须满足既定一年均值方差财富比例门槛；该估值器只由训练数据拟合，不随网络训练偷偷改变。回测按初始名义/实际财富100、真实建仓费、转移金额单次计费、扣费后应用收益和通胀递推。实现以实际金额持仓模拟可微路径，与名义金额引擎在舍入误差内等价；MDD包含扣费时点，25%已观察实际回撤后永久保持现有持仓。交易门槛用真实布尔分支，不以小额连续交易代理替代部署。

对每个期限H和原/双倍费用c，定义`g=log(W_H_real/100)/H`、`D=路径最大实际回撤`。原始目标最大化训练情景的平均g；风险约束为`CVaR90(D)≤CVaR90(D_ref)−0.01`，弱增长约束为`−CVaR90(−g)≥−CVaR90(−g_ref)−0.001`。参照为相同训练情景、期限和费用的年度Balanced。尾均值采用精确经验分位边界的分数质量，不把年度CVaR当作路径CVaR，也不把弱增长尾均值当P10 CAGR。

采用固定120轮Adam原始更新和投影对偶更新，按五个H循环，原/双倍成本在同一步成批处理。两约束分别按0.01和0.001标准化，对偶上限100、梯度裁剪5；所有参数固定，保存每个预定检查点。非凸、硬门槛和有限样本可能造成训练不可行或零梯度，均作为结果报告；不能静默调整风险预算。实现的学习率、容量、种子、检查点、内选及通过条件均在运行前登记于[PROTOCOL.md](PROTOCOL.md)。

代码实现分别由`neural_core.py`提供可移植推理，`neural_training.py`提供PyTorch float64路径训练，`neural_study.py`完成嵌套检查点选择与报告。验证采用生成市场有限差分梯度、PyTorch/独立NumPy/现有引擎三方递推核对、未来扰动测试及来源隔离；保存原始训练市场张量、所有成员参数、训练约束和内外层账本。数据图表包括18项风险区间、各外折训练约束可行性和训练轨迹，沿用成本/期限/严重情景图。训练与外层失败结果均保留，真实最终数据继续封存。

## 方法来源

- DeMiguel、Garlappi 与 Uppal（2009）：[Optimal Versus Naive Diversification](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=1376199)。支持认真设置 1/N 比较，以及对估计复杂度带来的收益保持审慎；其历史市场结论不能直接套用到本数据。
- Ledoit 与 Wolf：[Honey, I Shrunk the Sample Covariance Matrix](https://econ-papers.upf.edu/papers/691.pdf)。支持协方差正则化；本项目采用更简单的固定对角收缩。
- Rockafellar 与 Uryasev：[Optimization of Conditional Value-at-Risk](https://sites.math.washington.edu/~rtr/papers/rtr179-CVaR1.pdf)。经验 CVaR 的数学依据；本项目采用离散网格优化。
- Cawley 与 Talbot（2010）：[On Over-fitting in Model Selection and Subsequent Selection Bias](https://www.jmlr.org/beta/papers/v11/cawley10a.html)。支持嵌套选择及对重复使用开发集的偏差限制。

外部研究只用于方法设计；未引入外部金融收益或最终留出数据进行开发。
