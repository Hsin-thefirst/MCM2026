## SI-01：数据核验与探索

产物：`data.py`、`docs/DATA.md`、开发集探索笔记。加载器已完成，接着分析收益、通胀和相关性。

- [ ] 核验完整网格、主键、数值和文件 hash，坏输入明确报错。
- [ ] 固定整情景划分：1–120 开发、121–180 最终测试。
- [ ] 完成开发集统计与相关性分析，供估计器使用。

## SI-02：回测引擎

产物：`engine.py`，实现 `execute_trade` 和 `simulate`。

- [ ] 初始建仓只做一次，费用在收益前支付；三等分建仓费为 1/6，转移 20 的费用为 0.05。
- [ ] 策略只看到 t−1 以前历史；保持、再平衡、改目标和复核等待按接口执行。
- [ ] 输出 H 条年度记录，验证财富守恒、通胀换算和未来信息隔离。

## SI-03：风险与增长指标

产物：`metrics.py`，实现 `compute_metrics` 和 `summarize`。

- [ ] 按接口计算实际 CAGR、样本波动、MDD、交易率和费用。
- [ ] 验证手算路径：`100→120→90` 的 MDD 为 0.25。
- [ ] 先逐情景计算，再按同策略 / 同期限汇总，分位数采用线性插值。

## SI-04：组合与客户适配

产物：`suitability.py`、最终组合权重、期限风险表、`suitability.csv`。

- [ ] 在开发集校准三类组合，说明权重和筛选规则。
- [ ] 读取 `configs/profiles.json`，按 5/15/30/25/6 年给 A–E 推荐组合或转人工，附数值依据和解释。
- [ ] 若采用动态 Balanced，核对它在客户对应期限的风险。

## SI-05：等权与持有基准

产物：`policies/baselines.py`，实现 Policy 接口。

- [ ] `equal_weight` 每年恢复三等分，交易核算交给引擎。
- [ ] `balanced_buy_hold` 建仓后保持持仓，用于辅助比较。
- [ ] 验证目标恢复、自然漂移和实际交易次数。

## SI-06：固定 Balanced

产物：`policies/fixed.py`、可复用估计器、开发参数。

- [ ] 根据训练先验和已观察历史估计收益，处理短历史和退化协方差。
- [ ] 只在 `benefit > cost + buffer` 时恢复固定目标，记录估计收益、费用及理由。
- [ ] 在开发集确定参数，验证费用门槛，并输出交易率和成本。

## SI-07：动态 Balanced 与复核

产物：`policies/adaptive.py`、目标集合、复核规则、动作解释。

- [ ] 复用固定策略的估计器和评分，增加有限目标集合及目标切换。
- [ ] 定义回撤或分布偏离预警；复核优先，等待期间保持持仓。
- [ ] 记录四类动作和理由，支持 ≤50 词英文交易 / 改目标 / 复核解释。

## SI-08：实验入口与最终评估

产物：`evaluation.py`、CLI、配置、manifest、指标和决策日志。

- [ ] 在 1–120 内训练 / 验证，冻结权重、参数和复核规则后评估 121–180。
- [ ] 每情景新建策略；相同配置可复现，评估顺序不影响结果。
- [ ] 三种主策略按相同情景、成本和 30 年期限比较，输出四项主统计量、波动、交易率、成本及复核频率。
- [ ] 保存数据 / 配置 hash、代码版本和种子，补齐 README 运行命令。

## SI-09：成本敏感性与可靠性

产物：敏感性结果、复核案例和局限说明。

- [ ] 固定其他参数，对 `0 / 0.00125 / 0.0025 / 0.005` 成本率重新运行策略与引擎。
- [ ] 说明增长、损失和交易率的变化，以及是否改变采用动态目标的结论。
- [ ] 验证复核触发时序和等待行为，说明年度数据、尾部估计及合成情景的局限。

## SI-10：图表与严重案例

产物：`reporting.py`、比较表、实际财富路径和成本敏感性图。

- [ ] 图表从公共输出生成，标明指标、单位、期限和情景范围。
- [ ] 严重案例取动态策略测试 MDD 最大者，并列取较小 ID；展示各策略路径、动作和费用。
- [ ] 从日志选择一条 ≤50 词英文交易 / 改目标 / 复核解释，分析动态相对固定策略的增量价值。

## SI-11：英文报告与提交包

产物：`report/`、主报告、代码 ZIP 和复现说明。

- [ ] 覆盖组合、A–E 分配、主比较统计、严重案例、交易率、客户解释和可靠性实验。
- [ ] 结论回答是否采用动态 Balanced，明确复核条件和等待行为。
- [ ] 报告 ≤10 页 A4、字号 ≥11pt，附成员、来源和 AI 使用说明；代码 ZIP ≤50 MB。
- [ ] 数值对应保存的运行结果，队长在 2026-10-20 23:59 北京时间前提交。
